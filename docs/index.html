01 / 工作方式

前节与您交谈，
后节为您执行。

前车厢中，角色与您共商方案；后车厢中，古代机械专注执行。间隔之门，随时开启。

STEP 01

商议在前，执行在后

与白厄商讨任务内容。方案商定后方发出委派；若仅需交谈，列车亦可暂缓启程。

STEP 02

委派机械执行

商定之事将形成委派单，交由古代机械执行。文件与命令由其自主运行，执行过程以卡片形式呈现。

STEP 03

事毕回话，再续交谈

进度与结果均回报至同一场会话，白厄过目后再议下一步。机械自司其职，交谈照常进行。

02 / 搭档名录

一位伴您交谈，

03 / 功能

列车之上，一应俱全。

两种模式
CHAT / COLLAB
如需纯聊天，可选聊天模式，界面仅保留对话。协作模式将助手工作台置于一侧，任务执行与交谈并行不悖。
本地账号与设置中心
LOCAL ACCOUNT
账号存储于本机，每位用户各有其模型与语音设置，密钥仅回显掩码。Codex 的登录亦由此处统一管理。
项目即文件夹
LOCAL PROJECT
一个项目对应一个本地文件夹，名称取自文件夹名，可随时修改。路径同理，重新选择即可。
三档审批
APPROVAL
审批按项目配置，共分三档：逐项询问、机器自查、全程放行。是否放行，由您决定。
任务队列
QUEUE
机械执行期间，新任务先行排队。队列顺序可调整、可撤回，本轮结束后自动派发下一任务。
流式输出
STREAMING
思考过程与正文内容各自独立成流，实时呈现于界面。原始 JSON 存于技术详情之中。
编程助手
GPT-5.6 SOL
编程固定使用 gpt-5.6-sol，推理深浅随你调，想轻想重都可以。
语音对话
DASHSCOPE ASR / TTS
语音识别与合成经由 DashScope，VAD 随安装包内置。白厄的回复可朗读，工具记录与命令输出保持静音。
自动聊天标题
AUTO TITLE
新会话初始命名为「新聊天」，首轮回复结束后，由助手拟定标题。您自定义的名称将始终有效。
深色与浅色
THEMES
深色与浅色可自由切换。发言者一望即知：角色一色，机械一色。
04 / 架构

车底下，一根管子直通到底。

窗口由 Tauri 承载，状态由 Python Sidecar 维护，执行由 Codex 完成。

Desktop
桌面窗口
Tauri 2 · React · Rust

Rust 负责启动并拉起 Sidecar，文件夹选择调用原生接口，断线自动重连。React 渲染界面，工具事件以卡片形式进入工作台。

JSONL / stdio 请求带 ID
事件推流
Sidecar
Python 业务层
pair_harness · SQLite

业务状态统一收存于 SQLite。长任务并发执行，会话消息完整进出，取消操作亦经由同一通道。

app-server 委派任务
进度回报

A直接安装

Windows x64 安装包位于 GitHub Releases，Sidecar 与 Codex 一并封装其中。SmartScreen 弹出提示时，请选择「仍要运行」。

B体验演示模式

模型配置留空时，可先行体验演示模式；待配置填写完毕，即可切换至真实模式正式启程。

C运行真实模式

从源码运行时，首先运行 codex --version，确认 Codex 可用；再复制一份 .env.example，填入对话模型与 DashScope 的 key。
