# HSR Partner Harness v0.4.0

v0.4.0 是本轮产品路线的最终完整版：角色卡创作与酒馆兼容、自定义角色语音、手机远程公网接入和远程安全加固在本版本收口。角色负责对话，助手负责执行，全部业务数据与任务执行留在用户自己的 PC 上。

## 本版本变化

### 角色卡与创作

- 角色库、角色创作工作室与高级编辑：从基础信息逐步完成完整角色卡，也可直接编辑世界书、关系阶段、事件池等高级字段；创建、保存、编辑、复制、启用全部落库。
- 酒馆 Character Card v2/v3 双向兼容：JSON 与 PNG 导入导出，PNG 导出把头像与 v3 元数据合并为单文件卡；导入后重新导出保留未被应用识别的第三方扩展字段。
- 角色卡包含头像资产管理、世界书（关键字、常驻、插入顺序、深度提示）与 HSR 扩展字段；导入卡中的脚本类扩展只作为数据保存，不获得执行权限。
- mufy 高级字段进入 `data.extensions.hsr` 并有保存、装配与运行路径。

### 自定义角色语音

- 为创建或导入的角色上传参考音频，用用户自己的 DashScope 账号创建并保存该角色的音色；一个角色绑定一个音色，可重建或解绑。
- 语音 BYOK：模型固定为 ASR `qwen-audio-3.0-asr-flash-streaming` 与 TTS/声音复刻 `qwen-audio-3.0-tts-flash`，界面、配置文件与导入角色卡均不可更改模型。
- 只有角色自然语言回复可朗读；助手、工具、思考与系统事件在桌面与手机端均无 TTS 请求。

### 手机远程与公网接入

- 扫码配对一次带入配对码与桌面端服务地址；配对后可对话、发起委派、查看执行、处理审批并使用角色语音。任务完成、委派结果与审批请求的本地通知在 Android 壳内送达，浏览器端无系统通知。PC 侧全程可查看已配对设备并单键撤销。
- 内置 Cloudflare Quick Tunnel 托管（D1）：首次开启时下载官方 `cloudflared` 二进制、校验官方 SHA256 后作为子进程运行，手机端零安装直连 `https://*.trycloudflare.com`，HTTPS 满足麦克风安全上下文。
- 远程安全加固（D2–D7）：Sidecar 默认只监听 `127.0.0.1`，局域网直连需显式开启并常驻提示；配对码连续 5 次失败触发指数退避封锁；任意时刻仅一枚配对码有效；设备令牌 30 天绝对有效期与 7 天空闲有效期取先到期；生成配对码、列出与撤销设备、隧道开关等控制面方法只应答 PC 回环来源；PWA 静态目录在构建期校验，混入用户数据即构建失败。
- 真实失败如实呈现：隧道未就绪不显示已连接，下载、启动、外部强杀失败都给出真实原因。

### 桌面体验

- 同项目与跨项目多聊天并发互不串线；上下文压缩后角色上下文、世界书与单一助手提示词准确重建；配对记忆与聊天摘要按边界隔离。
- 登录页标语更新为「一条会话，两条工作轨。」。

## 手机远程使用前提

- 电脑需开机联网，Sidecar 与隧道进程随桌面应用运行；电脑休眠或退出后手机端如实显示断连。
- Quick Tunnel 主机名每次启动都会变化，二维码需重新生成；Cloudflare 将其定位为临时用途，长期稳定使用应自备域名的命名隧道；隧道流量经由 Cloudflare 边缘。
- 隧道地址会进入证书透明度日志，地址被看到不等于被接入；访问控制由配对码与设备令牌承担，请勿在公开场合张贴二维码截图。
- 模型与语音使用用户自备账号（BYOK），发布方不提供统一付费中转。
