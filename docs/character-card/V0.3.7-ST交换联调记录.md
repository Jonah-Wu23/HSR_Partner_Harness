## 4. L18 打包记录（同日）

- **打包链缺陷修复**：`desktop/scripts/build-sidecar.ps1` 的 mobile 段原依赖 `Push-Location` 切换 npm 工作目录——PowerShell 的 Location 不会同步子进程继承的工作目录，npm 实际跑在 desktop 根目录，`resources/mobile-dist` 自 V0.3.5 后从未被重建；且无 BOM 的 UTF-8 中文注释在 PowerShell 5.1（按 GBK 解析）下破坏语句解析，`$mobileRoot` 变空值后静默失败。修复：加 UTF-8 BOM + 显式 `cmd /c cd /d` 固定 npm 工作目录 + 失败以非零退出码如实暴露（不合成成功回执）。
- 修复后 `npm run build:sidecar` 全链路成功：`Bundled mobile PWA prepared`，mobile-dist 新鲜（含 V0.3.7 移动端产物）。
- 打包 sidecar EXE 冒烟：`resources/sidecar/pair-harness-sidecar/pair-harness-sidecar.exe --real --data-dir <临时>` 经 JSONL `app.bootstrap` + `power.get_status` → ok，返回真实电源数据（plan_name=平衡、AC=1800s、DC=120s），证明 V0.3.7 模块已进 PyInstaller 产物。
- release EXE：经 `tauri-with-first-run-reset.ps1 build --no-bundle` 重建（首次运行清理为必需步骤），产物 `desktop/src-tauri/target/release/hsr-partner-harness.exe`（版本 0.3.7）。未生成 NSIS（按仓库节奏，下次安装包更新在 V0.4.0）。
