视觉规则速记

唯一强调色

琥珀橙 oklch(0.72 0.15 65) 每屏至多出现两次；浅色主题同色相加深保证对比度。严禁蓝紫。

状态不只靠颜色

警告与 accent 色相接近，因此警告一律图标 + 文字双编码；音色状态用色点 + 文字标签。

样例数据显式标识

所有 mock 状态以虚线边框标签「样例数据」标注，与真实完成态视觉隔离，避免验收误读。
