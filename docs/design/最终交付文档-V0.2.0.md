## 2. 架构与协议总览

### 运行时
- Tauri 2（Rust）+ React + Python Sidecar（JSONL over stdio）+ SQLite。
- Rust 侧：sidecar 生命周期管理，EOF 分类（Shutdown/CleanExit/Crash）、
  指数退避自动重连、`sidecar_reconnect` 命令、合成事件序号。
- Python 侧：`DesktopApplicationService` 是唯一业务权威，命令 → 快照/增量事件。
- 前端：zustand store 水合 + 事件对账；presenter 映射视觉 ViewModel。

### 命令（Sidecar JSONL）
`app.bootstrap/shutdown`、`project.*`、`conversation.*`（含 set_mode）、
`chat.submit`（intent 参数）、`queue.edit/withdraw/prioritize`、
`task.cancel`、`approval.resolve`、`voice.vad_set/ptt_start/ptt_stop/
tts_stop/tts_play/tts_skip/preview`、`account.list/register/login/logout/
switch/update_profile/change_password/onboarding_complete`、
`config.get/set/test_connection`、`codex.oauth_start/oauth_status/logout/
api_login`、`app.reconnect`（Rust 侧接管）。

### 事件
`state.snapshot`、`message.created/status_changed/delta/finalized`、
`tool_run.upserted`、`turn.started/status_changed`、`queue.changed`、
`approval.requested/resolved`、`review.started/completed/failed`、
`task.busy_changed`、`conversation.changed`、`project.changed`、
`account.changed`、`connection.status`、`error.reported`（severity）、
`voice.state_changed/asr_partial`。

### 冻结原则（M1 确立，M2/M3 全程遵守）
1. 模式由后端按会话持久化；2. 即时回显使用真实 message_id；
3. 结构化 JSON 绝不进入气泡（raw 只进技术详情）。

## 5. 已知边界与真机验证项（交付 AI 必读）

- **Codex OAuth**：状态机与 API Key 登录已实现并单测覆盖；ChatGPT 浏览器
  OAuth 依赖 codex 官方流程与登录环境，需真机验证（`codex.oauth_status`
  轮询 auth.json）。
- **DeepSeek 编程助手（Reasonix ACP）**：适配器与 mock 测试完成；真机联调
  需本地构建 `reasonix acp` 二进制（`go build ./cmd/reasonix`）并配置
  `PAIR_HARNESS_REASONIX_BIN`。
- **VAD 随包**：`assets/models/silero_vad_v5.onnx` 需在安装后验证资源路径
  与初始化。
- **live 测试**：`tests/integration/test_text_loop_live.py` 的 module fixture
  会无条件 `load_dotenv(.env)`（skip 检查在之后）——单元测试已用
  monkeypatch 隔离，但运行 live 测试前注意环境变量污染顺序。
- **语音合成失败态**：tts 合成失败后清空待播队列并保持 failed 态（等待
  重播或新消息），不自动回落 idle——这是有意的可观测性设计。
- **设置中心推理等级**：模型页「推理等级」回显 config.get 的
  `dialogue.reasoning_effort="auto"`（硬编码）；真实权威是项目级
  reasoning_effort（Composer 菜单），保存不写该键。
- **构建**：⬜ 发布前执行 `npm run tauri build` + PyInstaller sidecar
  打包验证（VAD 路径随包）；`vite build` 已在 M5 通过。
