## 2. Sidecar JSONL 命令与事件

- 位置：`src/pair_harness/desktop_backend/commands.py`、`application_service.py`（V0.3.2 完成后的版本）。
- 建议命令（命名沿用现有动词风格）：
  - `card.list` / `card.get` / `card.create_draft` / `card.update` / `card.duplicate` / `card.archive`

  - `voice.bind_reference_audio` / `voice.create_for_card`（复用 V0.3.2 的 customization 客户端与账号级锁；进度事件沿用 `voice.provision_changed` 风格，附 `card_id`）

## 5. 语音链路接入（以实测为准）

- 复用 V0.3.2 的 BYOK 配置与 customization 客户端；为角色创建音色走 `voice.create_for_card`。
- **参考音频提交路径按《千问参考音频能力验证记录》执行**：
  - 本地音频 → Base64 data URI 放 `input.url`（实测成功，无需公网）；
  - 若人工排查时改走 URL，禁用 GitHub raw（实测稳定失败）；jsDelivr CDN 实测可用。正式运行时默认使用本地 data URI，不依赖 GitHub Release。
- 固定模型断言：请求装配处 `target_model == qwen-audio-3.0-tts-flash`；导入卡字段不参与模型选择。
- 角色自然语言回复才可进 TTS；助手、工具、思考、日志永久静音（V0.3.3 起 `tts_eligible` 规则）。
