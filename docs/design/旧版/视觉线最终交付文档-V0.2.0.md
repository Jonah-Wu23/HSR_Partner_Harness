## 4. 遵守的冻结原则自查

1. **模式不是纯前端状态**：界面只消费 ViewModel 的 `mode` 并发送 `switchMode`，未在 UI 层自建模式权威；工作台开合完全服从该字段。
2. **即时回显以真实消息为准**：未做前端乐观气泡系统；发送态样式等待真实 `message_id` 回执协议。
3. **流式 JSON 不上屏**：缎带与气泡只渲染干净文本；`payload.reasoning` 之外的原始结构化内容无任何渲染路径。
