### G. 自定义角色语音

设计角色语音创建流程：

- 选择角色
- 当前角色头像和名称
- 当前音色状态
- 选择本地参考音频
- 拖放参考音频
- 音频信息和试听
- 参考音频要求
- 账号未配置
- 创建音色
- 创建中
- 创建成功
- 音色 ID 已绑定
- 角色语音试听
- 重新创建
- 解除绑定
- 创建失败和真实错误
- 服务要求公网 URL 时的明确提示

界面中不允许用户修改模型名称。

固定模型：

- ASR：qwen-audio-3.0-asr-flash-streaming
- TTS、声音复刻和声音设计：qwen-audio-3.0-tts-flash

助手永远不使用 TTS。视觉方案中不要保留助手音色设置、助手试听和助手语音开关。
