# HSR Partner Harness v0.4.1

v0.4.1 修复桌面与手机会话在流式更新和长列表中的消息排版问题。新内容到达时，消息卡片按实际高度排列；用户翻阅历史内容时保留阅读位置，回到最新消息后恢复自动跟随。

## 会话消息流

- 桌面角色区、助手工作台和手机聊天页使用同一套动态高度消息列表。消息、工具调用、排队项和思考卡片在内容增长、展开及窗口宽度变化后重新测量，不再依赖固定估高放置卡片。
- 列表采用连续文档流排列虚拟窗口内的行，长会话只挂载可见范围附近的卡片，行高变化不会让相邻卡片叠在一起。
- 默认跟随最新消息。用户滚动、触摸、拖动滚动条或使用滚动键离开底部后，流式更新保持当前阅读锚点；滚回底部或使用“回到最新”后继续跟随。
- 工具卡片和思考卡片的展开状态按会话与消息身份保存，虚拟滚动卸载卡片后再返回仍保留状态。

## 验证

本版本使用模拟数据验证，不调用真实模型 API，不执行真实 app 验收或真机安装。Playwright 在 Chromium 中加载桌面和手机的实际 React 组件及生产 CSS，覆盖 39/40/41 条边界、500 条消息、工具卡片展开与虚拟化、流式更新时连续 12 帧的消息边界/滚动位置/阅读锚点，以及返回最新消息后的跟随恢复。失败时保留截图、视频和 trace。

JSDOM 测试覆盖状态与列表逻辑；浏览器中的真实布局结论以 Playwright 结果为准。验证结果：Python 离线测试 1207 项通过、4 项真实服务测试跳过；桌面前端 504 项通过，手机前端 365 项通过；Playwright 2 项通过；Rust 28 项通过且 `cargo fmt --check` 通过。桌面与手机 TypeScript 检查、生产构建均通过。
