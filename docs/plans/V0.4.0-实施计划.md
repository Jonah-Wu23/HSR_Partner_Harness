## 1. 范围

V0.4.0 是本轮产品路线的最终完整版，开发工作分两块：

1. **手机远程公网接入与安全加固**：按决策稿 D1–D8 落地 Cloudflare Tunnel 公网接入、监听面收窄、配对码限流与单码有效、设备令牌生命周期、控制面限回环、登录页标语更换。决策稿 §4 变更清单 20 项全部覆盖。

## 4. 协议契约增补（冻结）

在 V0.3.7/V0.3.9 既有契约之上增补以下内容。实现与测试以本节为准；本节与代码冲突时先改本节。

### 4.1 入口与模式

- `--serve <port>` 默认绑定 `127.0.0.1`；新增 `--lan` 参数时绑定 `0.0.0.0`。两参数可同用，`--lan` 只影响监听地址，不改变鉴权。
- `serve.started` 事件 payload：`{ host, port, mode, tls }`，`mode ∈ { "loopback", "lan" }`。隧道模式下该事件仍描述本地回环入口；公网入口只由隧道事件提供，前端不得用 `serve.started` 拼公网地址。

### 4.2 隧道方法（控制面，仅回环）

- `remote.tunnel_start` → 立即返回 `{ status: "starting" }`，后续状态经事件下发。
- `remote.tunnel_stop` → `{ status: "stopping" }`。
- `remote.tunnel_status` → `{ state, public_url, hostname, error }`，`state ∈ { "off", "downloading", "starting", "ready", "failed" }`，未就绪时 `public_url`/`hostname` 为 `null`，`failed` 时 `error` 为真实原因。

### 4.3 隧道事件

- `tunnel.started { public_url, hostname }`
- `tunnel.stopped { reason }`（含 Sidecar 退出前的有序关闭）
- `tunnel.failed { error }`（下载失败、哈希校验失败、进程退出、主机名解析超时均走此事件；不得先报 `started` 再报 `failed` 伪装成功路径）

审计条目同步增加 `tunnel_started` / `tunnel_stopped`（决策稿 §4 第 7 条）。

### 4.4 配对与鉴权错误语义

- `claim()` 失败区分三种结果：`invalid_code`（码不存在或已用）、`expired_code`（码已过期）、`rate_limited { retry_after_s }`（来源封锁中）。移动端按此三态给提示，不合并文案。
- `authorize()` 失败增加 `expired_token` 原因；手机端进入「授权已过期，请重新配对」状态，不静默重连。
- 远程连接调用控制面方法返回错误 `forbidden_scope`，并记审计 `scope_denied`。
- 限流参数：同一来源（以连接为单位）连续 5 次失败封锁 60 秒，继续失败退避翻倍，上限 30 分钟；触发写审计 `pairing_rate_limited`；封锁状态随配对状态持久化，重启不重置。

### 4.5 配对状态版本 2

- `_TokenEntry` 增加 `expires_at`：绝对有效期 30 天与空闲有效期 7 天取先到期者，每次成功鉴权刷新空闲计时。
- `export_state()` 的 `version` 从 1 升到 2；`load_state()` 接受版本 1，对缺 `expires_at` 的旧条目按 `issued_at + 30 天` 补算绝对有效期、按 `last_used_at + 7 天` 补算空闲有效期。
- `issue_code()` 生成新码时清空全部未过期旧码（单码有效）。

### 4.6 PWA 静态目录约束

打包流程加构建期校验：PWA 静态目录只允许构建产物（html/js/css/字体/图片/manifest/service worker），出现任何用户数据、账号信息或项目内容文件即构建失败（决策稿 D7「隧道 URL 不是秘密」——地址公开化的前提下，静态目录必须零用户数据）。

## 6. 真机验收矩阵（T16 执行依据）

决策稿 §5 的 11 项验收标准全部真实执行并留证，归纳为以下矩阵；另补公网语音一项。真机批次沿用只测不修纪律：批次内发现问题只登记，不现场改代码。

1. 默认启动只监听回环：另一台局域网设备访问 PC `:8765` 连接被拒。
2. 开启 `--lan` 后局域网可连且桌面出现暴露提示；关闭后提示消失、连接中断。
3. 公网隧道：手机在**蜂窝网络**（非同一 Wi-Fi）下打开隧道地址，HTTPS 加载，语音入口可用（麦克风 secure context 成立）。
4. 扫码配对进入对话；PC 重启后隧道主机名变化，旧二维码失效且界面如实提示。
5. 连续 5 次错误配对码后该来源被封锁，封锁期内正确码仍被拒，解锁后恢复；审计有记录。
6. 反复生成配对码，任意时刻只有最后一枚有效。
7. 已配对手机调 `remote.issue_code`/`remote.list_devices`/`remote.revoke` 全部 `forbidden_scope`；桌面端同样调用成功。
8. 手工把某设备令牌 `expires_at` 调到过去，该设备下一次请求被拒并提示重新配对；桌面端仍可撤销。
9. 撤销设备立即断连，重连被拒。
10. 隧道进程被外部杀死后桌面端显示真实失败状态。
11. PWA 静态目录校验在构建期拦截用户数据文件（可在 T10 离线完成，真机批次复核结论）。
12. 隧道模式下手机语音主路径：ASR 上行、角色回复 TTS 下行播放；助手与工具事件在手机端无 TTS。

V0.3.9 已验收的局域网/PWA/Android 壳/审批/电源矩阵不默认重跑；仅当本版本改动波及其路径时按影响面补测。

## 7. V0.4.0 发布门槛

路线图 §V0.4.0 发布门槛全部沿用，其中由本版本改动直接承担、必须逐项核对通过的为：

- 未配对或未鉴权的连接无法触发任何命令执行（含隧道公网入口）。
- 配对码限流、单码有效、令牌到期、控制面限回环四项安全行为与 §4 契约一致。
- 隧道真实状态不伪装：未就绪不显示已连接，失败如实显示原因。
- 真实失败未被转换为成功、空结果或伪造回执。
- 固定模型检查：运行时、界面、导入角色卡与手机端均无法改变 ASR/TTS 模型。
- 助手在桌面与手机端均无 TTS 请求；压缩后单 Markdown 重新注入检查通过。
- 同项目/跨项目多聊天并发不串线（回归既有测试即可）。
- 正式 EXE、NSIS 安装包、首次运行清理验证齐备；版本号统一 0.4.0。

角色卡、酒馆兼容、长期记忆等既有门槛项在 V0.3.9 已收口，本版本只做回归核对，发现回归即阻塞发布。
