# 发布说明索引

按版本从新到旧：

- `v0.4.2-release-notes.md`：当前产品基线。新建聊天的搭档目录接入角色库，导入或创建发布的自定义角色卡自动与现有助手组成可选搭档并保存为绑定；发布 Windows NSIS 安装包。
- `v0.4.1-release-notes.md`：历史版本。修复桌面与手机会话中的动态消息排版、自动跟随和阅读位置保持；发布 Android arm64 与 Windows NSIS 安装包。
- `v0.4.0-release-notes.md`：正式版，包括角色卡创作与酒馆 v2/v3 JSON/PNG 双向兼容、自定义角色语音、手机远程与 Cloudflare Quick Tunnel、远程安全加固 D1–D7。
- `v0.3.2-patch1-release-notes.md`：构建修复版，修复 rustfmt、并发测试竞态、PTT 测试断言三处 CI 问题。
- `v0.3.2-release-notes.md`：正式版，包括多聊天并发、Reasonix 只读探索、语音 BYOK。
- `v0.2.0-release-notes.md`：消息真实回执、独立聊天模式、流式输出等（对应 M0 基线 14 项问题的修复）。

v0.2.0 时代的方案与交付文档见 `../design/旧版/`。
