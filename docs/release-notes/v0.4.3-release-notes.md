# HSR Partner Harness v0.4.3

## 连续对话协议

历史角色消息统一序列化为 `{"speech": "已显示台词"}`，用户消息保持原文。请求明确区分历史台词投影与当前回合的完整 JSON 输出，当前回合按协议提供 `speech` 和 `delegate`。缺少必填字段时返回协议错误。

运行时输出协议作为最后一条独立系统消息发送，模型先输出 `delegate`，再输出台词。

OpenAI 兼容端点统一携带 `response_format={"type":"json_object"}`。DeepSeek 的 `thinking` 参数单独按供应商追加。

## 对话请求重试

对话流与 JSON 补全遇到连接或超时错误、HTTP 429/5xx 时自动重试。HTTP 200 的空白正文、响应格式错误和回合协议解析失败（包括缺少 `delegate`）也进入重试。首次请求失败后最多重试 7 次，依次等待 1、2、4、8、16、32、60 秒，单次等待上限为 1 分钟。每次请求的温度固定为 `1`，请求内容与 `response_format` 保持一致。

流式台词在确认 `delegate` 为布尔值后显示，字段尚未下发时暂存增量。已有角色台词增量显示在界面时，该回合保留现场并报告真实失败。重试耗尽也会报告失败，日志保留最后原始输出；每次重试记录轮次、等待时长与触发条件。

## 会话角色身份

桌面与手机共用身份解析函数，顶栏、会话列表和消息署名读取各自会话的 `character_identity`。角色身份尚未下发时显示加载状态，角色卡缺失或名字为空时显示“角色身份不可用”。

手机打开或重新装载聊天时，将完整会话写入索引及所属项目列表。角色改名后，界面继续通过已有会话更新事件刷新身份。

## 账号切换

切换账号并取消当前任务时，同时取消该会话的待审批请求，正在等待审批的任务可以正常结束。
