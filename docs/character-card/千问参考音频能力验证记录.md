## 探针与真实结果（响应原样保留，未改写）

### 探针 1：本地 WAV 以 data URI 放入 `input.url` —— 成功

请求：`input.url = "data:audio/wav;base64,UklGRiSzIgBXQVZF..."`（本地 WAV 全量 Base64，约 3MB）。

```json
HTTP 200
{"output":{"voice_id":"qwen-audio-3.0-tts-flash-vfylogic-39b2e1ad1dcd4978a5b3a2dc9d5053ac","preview_audio":{}},"usage":{"count":1},"request_id":"0d8a0b73-f0c6-9b06-aba6-d2d1b704c815"}
```

**结论：官方文档只写了 URL 形式，但真实端点接受 `data:` URI 放在 `input.url` 中，本地音频可以直接提交，无需任何公网托管。**（本记录基于 2026-08-16 的真实请求；后续若服务端收紧需以新实测为准。）

### 探针 2：本地绝对路径放入 `input.url` —— 拒绝

```json
HTTP 400
{"code":"InvalidParameter","message":"audio url should start with http or https","output":{},"usage":{"count":1},"request_id":"195ac136-0110-9ea9-b647-66d726918744"}
```

本地文件路径不能作为音频来源，错误信息明确要求 http/https 前缀。

### 探针 3：公网 404 URL —— 拒绝（证明服务端拉取）

```json
HTTP 400
{"code":"BadRequest.InputDownloadFailed","message":"download audio failed:404","output":{},"usage":{"count":1},"request_id":"ebf8ed18-6bdd-9a4b-95ae-8ce499d1b558"}
```

URL 形式的音频由 DashScope 服务端下载（本机 HEAD 该 URL 为 404，服务端如实回传 404 下载失败）。

### 探针 4：Qwen3-TTS-VC 载荷形态（`input.audio.data`）—— 拒绝

```json
HTTP 400
{"code":"InvalidParameter","message":"provide url, or provide both voice_prompt and preview_text.","output":{},"usage":{"count":1},"request_id":"b7024975-f7c1-96ce-aed9-a0a35a88d4a4"}
```

Qwen3-TTS 系列的 `audio.data` 字段不属于本固定模型的复刻契约；错误信息同时给出了两条合法路径：`url`，或 `voice_prompt + preview_text`（声音设计）。

### 探针 5：公网 URL（raw.githubusercontent.com）—— 稳定失败

URL：`https://raw.githubusercontent.com/Jonah-Wu23/HSR_Partner_Harness/main/assets/reference_voices/%E7%99%BD%E5%8E%84/phainon_concat.wav`（本机经代理 HEAD 200，与本地文件同为 2,274,092 字节）。

三次真实请求全部失败（错误信息一致，两次无状态码后缀）：

```json
HTTP 400
{"code":"BadRequest.InputDownloadFailed","message":"download audio failed","output":{},"usage":{"count":1},"request_id":"38fc6891-5972-9efc-af3e-2fc1f5b17a33"}
{"code":"BadRequest.InputDownloadFailed","message":"download audio failed","output":{},"usage":{"count":1},"request_id":"849c8631-bf33-9c1e-972c-43293bd8900a"}
{"code":"BadRequest.InputDownloadFailed","message":"download audio failed","output":{},"usage":{"count":1},"request_id":"bf9bf9af-33cd-9fb1-b2eb-c9987f2b4242"}
```

**结论：DashScope（北京地域）服务端无法稳定下载 GitHub raw 内容。** 小体积 404 响应能到达（探针 3 拿到 `:404` 回执），但 2.27MB 文件下载稳定失败，与「GitHub 在国内连接不稳定」一致。**GitHub raw 不能作为生产用参考音频托管。V0.3.2 已据此改为安装包本地音频转 data URI，GitHub Release 资产不再承担运行时依赖。**

### 探针 6：公网 URL（jsDelivr CDN，同一公开内容）—— 成功

URL：`https://cdn.jsdelivr.net/gh/Jonah-Wu23/HSR_Partner_Harness@main/assets/reference_voices/%E7%99%BD%E5%8E%84/phainon_concat.wav`（本机直连与代理 HEAD 均 200）。

```json
HTTP 200
{"output":{"voice_id":"qwen-audio-3.0-tts-flash-vfylogic-f0190066e15e4ed794ac0bbf76e70999","preview_audio":{}},"usage":{"count":1},"request_id":"06885d55-e163-9d44-9cdd-fe94710724ae"}
```

同一份文件经 jsDelivr CDN（有国内可达节点）即可成功创建音色，证明 URL 路径本身可用，问题特定于 GitHub raw 主机的国内可达性。

## 六个验证问题的答案汇总

| 问题 | 真实结论 |
|---|---|
| 1. 固定 TTS 模型接受哪些参考音频输入形式 | `input.url` 接受两种：http/https URL（DashScope 服务端可下载）与 `data:audio/*;base64,` URI（实测可用，文档未记载）。声音设计走 `voice_prompt + preview_text`。 |
| 2. 本地 WAV/MP3/M4A 能否直接提交 | **能**。读本地文件转 Base64 data URI 放入 `input.url` 即可（WAV 实测成功；MP3/M4A 同为文档支持格式，按同一通道提交，未逐一实测）。本地文件路径不能直接填。 |
| 3. 是否需要公网可访问 URL | **不是硬性要求**：data URI 路径无需公网。若使用 URL，则必须 DashScope 服务端可下载——GitHub raw 实测不可用，jsDelivr CDN 实测可用。 |
| 4. 创建音色 ID 的真实请求/响应结构 | 请求与响应见上文探针 1/6：成功响应为 `{"output":{"voice_id":"qwen-audio-3.0-tts-flash-{prefix}-{32hex}","preview_audio":{}},"usage":{"count":1},"request_id":"..."}`。 |
| 5. 音色创建失败时的原始错误 | 三类真实错误已原样记录：`InvalidParameter`（url 前缀非法 / 载荷形态非法）、`BadRequest.InputDownloadFailed`（服务端下载失败，含 `:404` 变体）。 |
| 6. 音色 ID 与角色卡绑定需保存的字段 | 见 `角色卡数据契约.md` 的 `hsr.voice_profile`：`state`、`voice_id`、`target_model`（固定）、`creation_mode`、`prefix`、`reference_audio_asset`、`reference_audio_url`、`voice_prompt_asset`、`last_error`、`updated_at`。**不保存 API Key**（Key 属于本地账号凭据存储）。 |

## 验证副作用与边界说明

- 本次真实验证在用户百炼账号下创建了 2 个测试音色（prefix `vfylogic`，Qwen-Audio-TTS 创建免费）：`...-39b2e1ad1dcd4978a5b3a2dc9d5053ac` 与 `...-f0190066e15e4ed794ac0bbf76e70999`。未用于合成，按官方规则一年不使用会自动清理；如需立即释放配额可用音色管理 API 删除。
- 未实测项如实列出：MP3/M4A 的 data URI 提交、超过 10MB/60 秒边界、新加坡地域端点、声音设计（`voice_prompt`）真实请求。这些不在本次验证条件内，不假设结论。
- 2026-08-17 审查已把本记录结论接入 V0.3.2：5 个复刻请求默认读取安装包本地音频并转为 data URI；公开 URL 只作备用记录。
