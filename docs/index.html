01 / 工作方式

一场会话，两种身份，
事情就办完了。

不用在聊天窗口和终端之间来回切。商量、委派、执行，发生在同一个地方。

STEP 01

先聊思路

和搭档讨论要做什么、怎么做。角色有自己的性格和说话方式，谈妥了再动手，不动手也可以只聊天。

STEP 02

委派给助手

谈好的任务形成结构化委派，交给助手处理。文件操作和命令执行都由助手完成，过程以卡片形式摆出来。

STEP 03

结果回到对话

执行进度和结果回报到同一场会话里，搭档根据结果接着聊下一步。任务跑着的时候，聊天也不会被卡住。

02 / 搭档名录

选一位搭档，
也选一位替你动手的助手。

每一对搭档都是「角色 + 助手」的组合：角色负责对话和商量，助手负责执行。v0.1.0 内置第一对，更多组合在航路上。

03 / 功能

一个桌面应用该有的样子。

两种模式
CHAT / COLLAB
聊天模式下整个界面只有角色对话，编程工具全部关闭；协作模式下对话和助手工作台并排显示，任务跑着也能继续聊。
项目即文件夹
LOCAL PROJECT
一个项目绑定一个本地文件夹，名字默认取文件夹名，随时能改。文件夹失效后可以重新选择路径。
三档审批
APPROVAL
每个项目单独选择审批方式：请求批准、自动审核、完全允许。敏感操作放不放行，由你按项目决定。
语音对话
DASHSCOPE ASR / TTS
语音走 DashScope 的识别和合成，角色的自然语言回复可以朗读，工具记录和命令输出保持静音。
自动聊天标题
AUTO TITLE
新会话先叫「新聊天」，第一次完整回复结束后由助手生成标题；你手动改过的名字不会被覆盖。
深色与浅色
THEMES
两套主题随你换。搭档的配色也进了界面——角色的颜色和机械的颜色，一眼就能分清谁在说话。
04 / 架构

窗口后面，是一条窄而清楚的管道。

桌面端只管窗口，业务状态都在 Python Sidecar 里，编程执行交给你本机装好的 Codex。

Desktop
桌面窗口
Tauri 2 · React · Rust

Rust 负责启动 Sidecar 和原生文件夹选择，React 渲染界面。工具事件以结构化卡片进入工作台。

JSONL / stdio 请求带 ID
事件推流
Sidecar
Python 业务层
pair_harness · SQLite

会话状态、项目记录和审批模式都存在这里。长任务并发执行，聊天消息照常进出，取消走同一条通道。

app-server 委派任务
进度回报
Execution
Codex 编程后端
OpenAI Codex · 本机

真实的文件操作和命令执行由本机 Codex app-server 完成。仓库不含 Codex 源码，版本以你本机为准。

对话模型 DeepSeek / OpenAI 兼容接口 语音 DashScope ASR + TTS 数据 %LOCALAPPDATA%\PairHarness
05 / 快速开始

三分钟，让搭档开工。

PowerShell · 从源码运行 
# 需要 Python 3.11 · Node.js 22 · Rust stable
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[voice,dev]"

Set-Location desktop
npm install
npm run build:sidecar
npm run tauri:dev

A直接装

Windows x64 安装包发布在 GitHub Releases。安装包没有代码签名，SmartScreen 弹提醒属正常现象。

B先玩 demo

不填模型配置时应用进入 demo 模式，界面和交互照常体验，只是不调用真实模型。

C跑真实模式

确认本机 codex --version 可用，再复制 .env.example 填上对话模型和 DashScope 配置即可。
