头像

样例数据

头像支持上传与几何占位两种模式。未上传时会自动生成带琥珀橙渐变的占位图，之后可在角色编辑器中随时更换。

几何占位 · 自动生成
上传入口：角色编辑器 → 头像设置 → 选择图片（PNG / JPG，≤2MB）

配置 DashScope 账号

样例数据

音色创建与语音合成都调用 DashScope 服务。填入 API Key 后点击「前往验证」，验证通过才能使用语音功能。

未配置 DashScope API Key。语音功能（音色创建、回复朗读）将不可用，可先跳过，稍后在「角色语音」页配置。
