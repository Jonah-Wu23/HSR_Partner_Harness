# HSR Partner Harness v0.4.2

v0.4.2 把角色库接入新建聊天的搭档目录。导入或创建并发布的自定义角色卡会自动与现有助手组成可选搭档，出现在新建聊天菜单中并显示角色名与头像；点选的搭档保存为绑定，新建会话严格按该身份运行。角色档案的改动会实时反映到目录与会话展示。

## 搭档目录

- 新建聊天菜单列出全部可选搭档，每组由一张角色卡与一个助手组成，展示角色名与头像。
- 从角色库导入或现场创建并发布的角色卡自动参与组队，无需额外配置。
- 角色改名、更换头像、归档或删除后，目录中的展示实时同步。

## 搭档绑定

- 搭档选择持久化为绑定（`partner_bindings`），重新打开应用后仍然保留。
- 新建会话严格按点选的搭档身份运行，会话中的角色名与头像随角色档案变化实时更新。

## 本版修复

- 从角色库或创作页开始对话时，会话固定创建到当前窗口正在查看的项目；多窗口交错操作下，新建与复用都遵循同一归属规则，助手任务的工作目录不再串到另一个窗口停留的项目。
- 从旧版本升级后，已归档角色恢复时会在同一事务里补齐搭档绑定，恢复后即可在新建聊天菜单中选择；v15 迁移同时为此前漏掉的归档角色与旧会话补建绑定。
- 角色发布事务纳入统一回滚边界：绑定创建或目录版本写入失败时，角色状态、绑定与版本整体回退，重试发布可正常完成；重复发布幂等补齐缺失绑定。
- 聊天面板标题、消息署名、委派来源、语音条与手机端聊天统一按各自会话的角色身份展示，自定义角色会话不再残留内置角色姓名。
- 角色改名、更换或移除头像、删除（含归档后删除）后，正在查看该角色会话的窗口经 `conversation.changed` 即时收到最新身份，删除后呈现明确的缺失状态。
