## 2. 铁律

1. **Let It Fail**：不吞异常、不合成成功事件、不用兜底文本掩盖未执行的任务。修复直击已定位的根因，不加未经证实的兼容分支。测试失败如实报告。
2. **Let It Go**：不在代码层用关键词、正则、探针猜测或改写模型意图与措辞。代码只做协议校验与安全边界。
3. **测试边界（用户明确要求）**：严禁使用 computer use 操作真实桌面 GUI，严禁 adb 操作安卓真机，严禁任何真机测试。允许并优先使用模拟测试：vitest / pytest 单元与集成测试、脚本模拟进程行为（如 `taskkill` 强杀 `cloudflared`）、对 Sidecar stdout 事件流的脚本断言。
4. **提交纪律**：提交时写明文件路径，严禁 `git add -A`。`docs/promo/`、`evidence/`、`.archive/` 受 Git 忽略或属本地资料，不得提交。每个阶段结束提交一次，提交信息写清改了什么、为什么。
5. **发布授权（用户书面授权，覆盖 AGENTS.md「未经授权不发布」条款）**：用户已明确授权你执行合并 main、打 `v0.4.0` tag、创建 GitHub Release 并上传 NSIS 安装包，到时自动执行，不必再请示。**唯一前提：PR 的 CI 必须全绿才能合并；CI 有任何红项，修复后重新推送等待，严禁强行合并。**
6. **审核门禁**：阶段一到六结束时，开独立审核子代理（独立的上下文窗口，只读权限），把该阶段的审核清单、相关文件路径和仓库位置交给它，**不要把你自己的结论喂给它**。要求它逐项核对并输出 `PASS` 或 `FAIL` 加证据（文件:行号、命令输出）。FAIL 就修复后重新审核，直到 PASS。审核子代理不得修改任何文件。
7. **版本事实**：当前版本号已是 0.4.0（`src/pair_harness/__init__.py`、`desktop/src-tauri/tauri.conf.json`、`desktop/package.json`），不要再改版本号。
