# V0.4.0 角色卡功能 — UI 设计方案（设计计划）

## 意图摘要

为 HSR Partner Harness V0.4.0 角色卡功能设计完整的视觉与交互原型，覆盖角色库、角色创作（快速创建 + 高级编辑）、头像、导入导出、世界书、mufy 高级字段、角色语音、新用户引导八条主线。本阶段使用样例数据与 mock 状态，产出可运行的高保真 HTML 原型，供用户验收视觉方向，并为强逻辑 AI 输出数据字段与后端能力清单。

**硬性视觉约束（用户本轮明确要求）：**
- 严禁蓝紫配色。Linear 方向的靛紫 accent（#5e6ad2）不得出现在任何 token 中。
- 严禁 emoji 作为功能图标或装饰。图标一律使用线性 SVG。

---

## 1. 视觉方向

### 1.1 设计语言

融合三个参考方向、去除蓝紫后的自有语言：

- 来自 Agentic：对话优先、控制极简化、任务委派流程清晰可见。
- 来自 Linear：超克制、精确、1px 边框、8px 圆角、密集但呼吸均匀的信息排布。
- 来自 Bento：模块化卡片网格组织复杂信息（世界书条目、mufy 分区、角色库卡片）。

### 1.2 色彩系统（OKLch token，替代蓝紫）

**已确认：accent 用琥珀橙。** 双主题（暗色优先 + 浅色版）共用同一套 token 结构，浅色版只换 L 值、保持色相一致。

暗色主题（默认）：

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | oklch(0.14 0.008 60) | 近黑微暖底色 |
| `--surface` | oklch(0.18 0.008 60) | 卡片 / 面板 |
| `--fg` | oklch(0.95 0.005 70) | 主文字 |
| `--muted` | oklch(0.62 0.012 60) | 次要文字 |
| `--border` | oklch(0.25 0.008 60) | 1px 分隔线 |
| `--accent` | oklch(0.72 0.15 65)（琥珀橙） | 唯一强调色，每屏 ≤ 2 次 |

浅色主题（`data-theme="light"`）：

| Token | 值 |
|---|---|
| `--bg` | oklch(0.97 0.005 75) |
| `--surface` | oklch(0.99 0.004 75) |
| `--fg` | oklch(0.22 0.01 60) |
| `--muted` | oklch(0.5 0.012 60) |
| `--border` | oklch(0.88 0.006 70) |
| `--accent` | oklch(0.62 0.16 60)（同色相加深，保证白底对比 ≥ 4.5） |

- 状态色：成功 `oklch(0.7 0.15 150)`、警告 `oklch(0.78 0.14 85)`、失败 `oklch(0.6 0.2 25)`；琥珀橙 accent 与警告色相接近，警告状态一律配图标 + 文字，不靠颜色单独传达。
- 主题切换入口放设置与原型总览页，用 `data-theme` 属性切换，localStorage 记忆。
- mock 状态统一用「虚线边框 + MONO 小字标签 `样例数据`」标识，与真实完成状态视觉隔离。

### 1.3 字体

- Display：思源宋体 / Noto Serif SC（角色名、页面大标题，给角色卡内容以"文本作品"感）
- Body：Inter + 系统中文字体栈（界面与正文）
- Mono：JetBrains Mono（ID、字段名、状态枚举、技术元数据）

### 1.4 布局基元

- 8px 基线网格、8px 圆角、1px 边框。
- 工作台三段骨架：左导航栏（角色库 / 创作 / 语音 / 设置入口）· 主内容区 · 右侧情境面板（预览 / 状态 / 帮助）。
- 所有图标为 16px/20px 线性 SVG，笔画 1.5px，不用 emoji。

## 3. 关键页面设计要点

### 3.1 角色库

- 顶部：页面标题 + 搜索框 + 筛选（来源：内置/创建/导入/草稿；音色状态；使用状态）+ 两个次级按钮「导入角色」「创建角色」（创建为主 CTA，每屏仅一个实心按钮）。
- 卡片网格（Bento）：头像、名称、标签、来源徽标、音色状态点（未配置/创建中/失败/已绑定）、最近编辑时间、「使用中」标记。
- 卡片悬停浮出操作：编辑 / 复制 / 导出 / 删除（删除为危险色文字项，二次确认弹窗）。
- 空态：大号线性插图位 + 一句话引导 + 主 CTA「创建第一个角色」。
- 状态覆盖：头像缺失（首字符占位）、导入失败角标、音色创建中骨架动画。

### 3.2 角色创作页（快速 + 高级同一份数据）

- 顶部模式切换：`快速创建 | 高级编辑`，切换不清空任何字段，标题旁常驻「未保存更改」状态点。
- 快速创建：左表单（名称、头像、标签、简介、性格、对话场景、第一条消息、示例对话）右固定预览卡（实时渲染角色卡样貌）。底部「保存草稿」（次级）+「完成创建」（主 CTA）。
- 高级编辑：左侧分区树（系统提示 / 历史后指令 / 备选问候 / 群组问候 / 世界书 / 世界架构 / 身份外貌 / 语言方式 / 行为状态 / 心理核心 / 用户关系 / 关系阶段 / 时间线 / 叙事规则 / 声音感官 / 声明式面板 / 原始数据），分组折叠；面包屑常驻显示当前编辑位置；右上「角色整体预览」随时可回。
- 长文本字段用自动增高 textarea + 字数统计；原始数据为只读 JSON 视图（mono 字体、语法着色）。

### 3.3 头像流程

- 弹层三步：选择（点击 / 拖放）→ 裁切（1:1 圆形预览 + 缩放滑杆 + 拖动构图）→ 确认。
- PNG 角色卡：显示嵌入头像预览；JSON 卡无头像时显示「无内嵌头像」占位 + 提示稍后补传。
- 替换 / 删除为头像区的次级文字操作，删除需确认。
- 演示用头像一律为占位图：无头像时用名称首字符占位块（surface 底色 + Display 字），有头像状态用几何色块占位，不生成真实人物图像。

### 3.4 导入流程

- 全宽拖放区（虚线边框）支持 JSON/PNG，读取中为骨架态。
- 导入预览卡：名称、头像、Character Card 版本徽标、备选问候数、世界书条目数、已识别扩展清单、「已保留但暂未运行」扩展灰态清单。
- 名称冲突：弹窗给出「作为副本导入」（建议，主按钮）/「取消」。
- 失败态：失败图标 + 原始错误摘要（mono 代码块）+「重试」——绝不用默认角色掩盖。

### 3.5 导出流程

- 两步：选择格式（v3 JSON / v3 PNG，单选卡片）→ 预览（文件名可编辑、头像/世界书/扩展字段状态逐项打勾或警示、保存位置）→「导出」主 CTA → 完成 / 失败态。

### 3.6 世界书编辑（独立页面）

- 从高级编辑器左侧分区树的「世界书」项跳转进入，顶部面包屑可返回所属角色。
- 左侧条目列表：可拖动排序（拖柄）、启用开关、常驻/选择性徽标、主关键字摘要；顶部搜索定位 +「新增条目」。
- 右侧编辑区：主/次关键字、插入顺序、插入位置、深度、内容（大编辑区）、条目预览页签。
- 大量条目：列表虚拟滚动的视觉表达 + 当前位置指示。

### 3.7 角色语音

- 顶部角色卡条（头像 + 名称 + 当前音色状态徽标）。
- 流程：选择本地参考音频（点击/拖放）→ 音频信息卡（时长/格式/大小 + 试听播放器）→ 参考音频要求说明 →「创建音色」主 CTA。
- 状态机完整呈现：未配置 / 账号未配置（引导去设置）/ 创建中（进度 + 可取消）/ 成功（音色 ID 已绑定 + 试听）/ 失败（真实错误 + 重试）/ 公网 URL 要求的明确提示条。
- 固定模型展示为只读信息行（ASR / TTS 型号），无编辑控件；不出现任何助手语音相关设置。

### 3.8 新用户引导

- 顶部九步进度条（当前步 accent 高亮，已完成打勾），每步一张引导卡 +「下一步」，直接嵌入对应页面的真实组件（非截图），步骤间平滑过渡。

## 4. 交互规则

- 主 CTA 每屏一个实心按钮；其余入口均为次级 / 幽灵 / 文字按钮。
- hover：背景 L 值 ±0.06–0.12，或边框/阴影变化；文字颜色绝不向 muted 方向降对比。
- 所有可聚焦元素有清晰 `:focus-visible` 焦点环（accent 色 2px）。
- 危险操作（删除、解除绑定）统一：文字项 → 确认弹窗（说明后果）→ 主按钮为失败色。
- 触控目标 ≥ 44px；无横向滚动。
- mock 数据标识贯穿所有页面，导出的「等待后端接入清单」与之对应。

## 7. 风险与边界

- 不修改 V0.3.2 在开发的文件；所有产出为独立原型文件，与正式代码零耦合。
- mock 状态若被误认为真实后端能力会破坏验收，标识系统必须每页可见。
- 高级编辑字段极多，分区导航 + 面包屑 + 随时回预览是防止用户迷失的三道保险，需在原型中验证。
