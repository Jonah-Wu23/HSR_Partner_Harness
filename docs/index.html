01 / 工作方式

前节与您交谈，
后节为您执行。

角色负责情感陪伴与意图商定，助手专注系统与工程执行。同屏双空间，各司其职，互不越界。

STEP 01

商议在前，意图对齐

与角色商讨需求与思路。只在方案明确后形成委派；若只是闲聊或情绪宣泄，列车便只作静静陪伴。

STEP 02

结构化委派，工具落地

商定结果转为底层任务委派单，助手经由本机 Codex / DeepSeek 引擎自主运行文件与命令，过程以结构化卡片直观呈现。

STEP 03

结果回流，对话接续

进度与真实执行结果自动回流到对话中，角色依此给出总结与下一步提议，无需切屏，对话自然流转。

03 / 功能特性

列车之上，一应俱全。

V0.3.0 带来完整的搭档目录、多主题动态令牌与端到端双空间消息流转体系。

搭档目录与选择
PAIR CATALOG
新建聊天时可自由挑选搭档，会话列表按各会话自身 pair 渲染头像与芯片；切换历史会话自动换取专属色组，重启不串角色。
两种模式
CHAT / COLLAB
聊天模式仅保留纯粹的自然语言交流；协作模式同屏展开助手工作台，代码编写、命令运行与角色对话互不干扰。
多搭档动态主题
DATA-PAIR TOKENS
三组搭档各有一套深色与浅色 7 色设计令牌。跟随当前选中会话实时切换界面气质，告别单调默认配色。
本地账号与设置中心
LOCAL ACCOUNTS
多账号数据隔离于本机 SQLite，密钥仅回显掩码。提供对话模型配置、编程助手登录与各搭档专属音色试听。
项目即文件夹
LOCAL FOLDER
项目天然绑定本地工程文件夹，支持路径可用性自动检测与一键重选，所有文件读写均在受控工作区内进行。
三档安全审批
APPROVAL MODES
每个项目可独立设定审批档位：逐项确认、机器自查、全自动放行。危险文件操作与命令由用户掌握最终控制权。
任务队列与实时排队
QUEUE STRIP
助手忙碌时发送的消息自动进入排队胶囊条，支持调整执行顺序、拉回输入区重编辑或随时撤回。
双通道思考流式呈现
DUAL STREAMING
模型思考过程与最终正文双流独立解析，角色回复前先展现思绪缎带，完成后自动折叠，保持阅读清爽。
专属音色复刻与 VAD
VOICE REPRODUCTION
基于 DashScope 打造专属复刻人声，角色自然台词进语音朗读，工具事件与日志天然静音；支持按键发话与智能 VAD 聆听。
04 / 架构设计

车底下，一根管子直通到底。

Tauri 2 承载桌面，Python Sidecar 维护业务状态，Codex 与 DeepSeek 承担底层执行。

Frontend & Native
桌面窗口
Tauri 2 · React · Rust

Rust 负责启动并守护 Python Sidecar，原生目录选择，断线重连；React 负责视图渲染与 40ms 高效事件合批。

JSONL / stdio 请求带 ID
序号单调推流
Core Engine
Python 业务层
pair_harness · SQLite

状态以 SQLite 为唯一事实来源。管理三组搭档 YAML、多会话隔离、任务编排、TTS/ASR 语音适配与审批状态机。

app-server 结构化委派
真实结果回流
Execution Agent
编程执行后端
OpenAI Codex / DeepSeek

文件修改、环境探测与终端命令执行均由底层 Agent 处理，严格遵从 Let It Fail 原则，绝不粉饰真实失败。

对话模型 DeepSeek / OpenAI 兼容接口 语音链路 DashScope ASR + TTS · 智能 VAD 连接韧性 三态药丸 · 后台自动重连 持久化路径 %LOCALAPPDATA%\PairHarness
