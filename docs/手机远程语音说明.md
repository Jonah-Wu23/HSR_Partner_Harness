# 手机远程语音说明

本指南面向想在手机浏览器上用「按住说话」和角色对话的用户，说明为什么需要 HTTPS、为什么采用 Cloudflare Quick Tunnel 方案、怎么打开通道、接入时要注意什么、已知限制与安全认知。

适用版本：V0.4.0 及以后。V0.3.5—V0.3.9 的旧方案（依赖 Tailscale 组网）已退出推荐路径，升级后请按本文操作。

---

## 一、为什么手机上需要 HTTPS 才能用语音

现代手机浏览器（iOS Safari、Android Chrome 等）把麦克风音频采集（`getUserMedia` API）严格限制为**安全上下文（Secure Context）专属能力**：只有通过受信任的 HTTPS 加密连接打开的网页，才被允许请求并调用麦克风。这是所有浏览器统一执行的平台级安全红线，**不是本应用的缺陷**。

桌面端默认只在电脑本机（回环地址 `127.0.0.1`）上提供服务，手机无法直接访问。即使用户按下文「方式三」以进阶配置开启局域网直连，那条通道也是纯 HTTP 的。在纯 HTTP 地址下：
- 配对、聊天列表、文字消息、委派任务查看、代码审批等功能完全可用；
- 但手机上的**语音入口会被如实禁用**，并明确提示缺少 HTTPS 安全上下文。

应用不会伪造麦克风可用状态，也不会引导用户绕过浏览器的安全检查。要让手机语音开箱即用，必须为手机提供一条带权威证书的 HTTPS 入口。

## 二、方案演进：为什么推荐 Cloudflare Quick Tunnel，Tailscale 退出推荐路径

在 V0.3.5—V0.3.9 期间，手机远程接入曾推荐用户搭建 Tailscale 虚拟局域网。但在实际使用中，Tailscale 存在明显的门槛与体验断层：
1. **安装门槛高**：需要在 PC 和手机两端分别下载安装 Tailscale 客户端、注册账号并完成组网。
2. **HTTPS 证书痛点**：在移动端浏览器唤起麦克风必须要有 HTTPS。自签名证书需要用户手动将 CA 根证书导入手机系统并在证书信任设置中逐项放行，步骤极其晦涩且常被手机浏览器弹窗警告拦截；而自建域名或公网反代又要求公网 IP 与解析配置。

**V0.4.0 正式改为内置 Cloudflare Quick Tunnel 方案，Tailscale 退出官方推荐路径：**
- **零客户端安装**：手机端直接使用系统自带浏览器扫码即开，无需安装任何 App 或 VPN。
- **免自签证书体验**：Cloudflare 边缘节点直接提供公信机构颁发的权威 TLS 证书。手机浏览器打开时**零安全警告、零证书导入**，直接成立 Secure Context，麦克风权限一键授权即可使用。
- **无需公网 IP 与路由器打洞**：PC 端由内置的 `cloudflared` 进程主动向 Cloudflare 边缘发起安全长连接，流量经隧道反向回传，对用户的家庭宽带或局域网网络拓扑零要求。
- **兼容自备网络**：对于熟悉网络配置的高级用户，若已有自建反向代理、自有域名证书或仍希望使用 Tailscale 组网，应用继续完全兼容（只要将请求转发至 PC 本机回环服务端口即可），但 Tailscale 不再作为普通用户的主推荐路径。

## 三、Quick Tunnel 使用流程

### 方式一：在桌面应用内一键开启（推荐）

1. **确认桌面端正在运行并进入主界面**。隧道生命周期绑定在桌面端应用上。
2. **打开「设置 → 远程设备」**，找到「公网接入」开关并点击开启。
   - 首次开启时，应用会自动下载官方 `cloudflared` 组件（约 45 MB）并执行 SHA256 哈希校验，界面会如实显示下载与校验进度。
3. **等待状态变为「已就绪」**。
   - 就绪后，界面会显示本次会话分配的 `https://<随机主机名>.trycloudflare.com` 地址，并自动生成包含该地址的配对二维码。
4. **手机扫码或浏览器访问该地址**。
   - 手机可以使用蜂窝移动网络（4G/5G）或任意 Wi-Fi，不必和电脑在同一个局域网内。
5. **完成配对**：
   - 在电脑端「设置 → 远程设备」查看当前生成的 6 位配对码。
   - 在手机端配对页输入该配对码（可同时为手机命名），点击完成配对。
   - 配对成功后自动进入聊天页面，底部的语音输入控件即可直接使用。

> **关闭与清理**：在桌面端随时关闭「公网接入」开关即可断开隧道并终止子进程；退出桌面应用时也会自动关闭隧道，不留孤儿进程。隧道关闭后，所有外部连接即刻中断。

### 方式二：自建隧道或反向代理（进阶）

已有自有域名、自签权威证书或自建反代（如 Nginx、caddy）的高级用户，可继续使用自己的基础设施：
- 反向代理目标：指向 PC 本机回环地址 `127.0.0.1:8765`（支持 WebSocket 升级）。
- 外部入口提供受信任的 HTTPS 证书。
- 手机端直接访问你的私有域名完成配对。

### 方式三：同网局域网直连（进阶，语音不可用）

手机与电脑在同一局域网、且不希望流量经过 Cloudflare 时，可以显式开启局域网直连。该模式默认关闭，属于纯 HTTP 的降级通道：手机端语音入口会被如实禁用，只保留配对、文字对话、任务查看与审批；访问控制由配对码与设备令牌承担，开启后桌面端「设置 → 远程设备」会显示「局域网已暴露」警示（公网隧道就绪期间该警示会让位于隧道状态）。

两种开启方式（二选一，重启应用后生效）：
- 启动参数：以 `--lan` 参数启动应用（修改桌面快捷方式目标，或在终端运行）。
- 配置文件：在 `%LOCALAPPDATA%\PairHarness\.env` 中写入一行 `PAIR_HARNESS_LAN=1`（安装版路径；源码运行为仓库根目录 `.env`）。

开启后手机浏览器访问 `http://<电脑局域网IP>:8765` 完成配对。

## 四、Quick Tunnel 的三项已知限制

用户在使用 Cloudflare Quick Tunnel 时，需要知晓以下三项固有技术限制：

1. **主机名每次开启都会变化**：
   - Quick Tunnel 是临时免注册隧道，每次开启公网接入或电脑/应用重启后，Cloudflare 都会重新随机分配一个新的 `*.trycloudflare.com` 域名。
   - 上一次的主机名和历史二维码在重启后永久失效。每次重新开启隧道后，手机端都需要重新扫描最新二维码或输入新地址配对。
2. **临时体验定位，不提供商业 SLA**：
   - Quick Tunnel 是 Cloudflare 官方提供的免费试用与轻量分享服务，定位为临时与开发测试通道，不保证 99.9% 持续在线 SLA。
   - 偶发情况下可能遇到 Cloudflare 边缘节点网络抖动或隧道连接被云端调度重置，重新开关公网接入即可恢复。
3. **流量经由 Cloudflare 全球边缘节点**：
   - 手机与电脑之间的通信流量全程走 TLS 加密隧道，但在链路中间是由 Cloudflare 边缘节点中转解密后送达 PC，并非端到端点对点（P2P）直连。

## 五、安全认知与鉴权防线（D7 核心准则）

将服务接入公网后，安全边界从“网络隔离”完全转移为“协议鉴权”。用户必须建立以下安全认知：

### 1. 隧道 URL 不是秘密，“地址被他人看到不等于被接入”

`*.trycloudflare.com` 颁发的所有 TLS 证书都会按照国际公钥基础设施规则实时写入公开的**证书透明度日志（Certificate Transparency Log）**。全球任何网络扫描器、安全爬虫都能秒级枚举到新生成的主机名并尝试发起 HTTP 请求。

- **公网暴露是常态**：地址被扫描器探测到是公网服务的正常现象。
- **安全不靠隐匿**：系统决不把“地址只有自己知道”当作安全手段，**“地址被他人看到绝对不等于被接入”**。
- **切勿外传配对码**：切勿在公开论坛、群聊或社交网络张贴包含当前配对码的完整二维码截图。

### 2. 真正的防线：鉴权与控制面三重安全防护

在隧道模式下，未配对的公网连接唯一能访问的只有受严格保护的配对接口，系统通过以下三道防线确保宿主机安全：

- **第一道防线：配对码限流与单码有效（D3 / D4）**：
  - 配对码为 6 位数字，由桌面端主动生成，默认短期有效。
  - **单码有效**：每次在桌面端生成新码，未过期的旧码立即全部作废，任意时刻系统内只有最后一枚配对码处于有效状态。
  - **失败限流与阶梯封锁**：未鉴权连接若连续输错 5 次配对码，该来源将被强制暂时封锁（封锁期内即使输入正确码也会被直接拒绝），且封锁时间随失败次数指数递增（上限 30 分钟）。暴力穷举攻击在数学和时间上完全不可行。
- **第二道防线：设备令牌生命周期与可撤销（D5）**：
  - 配对成功后签发唯一的设备访问令牌（Token）。
  - 令牌具备严格生命周期：最长绝对有效期为 30 天，若连续 7 天未发起任何请求则自动失效。
  - 令牌过期后手机端会自动提示重新配对。
  - 桌面端「设置 → 远程设备」可实时查看所有已配对设备，点击“撤销”可瞬间作废该令牌并强制手机断开连接。
- **第三道防线：控制面强收窄至本机回环（D6）**：
  - 敏感控制接口（生成配对码、列出设备、撤销设备、开关隧道等）在服务端做了严格的调用来源判定，**仅允许来自电脑本机回环地址（127.0.0.1 / Stdin）的请求调用**。
  - 远程手机客户端即使配对成功，也仅拥有对话、语音交互和委派审批等日常使用权限；若尝试调用控制面接口，服务端会直接拦截、返回 `forbidden_scope` 错误并记录安全审计。

## 六、明确的产品与商业边界

- **不内置自签证书方案**：应用不提供且不推荐自签证书，不引导用户忽略浏览器的不安全风险提示。
- **不运营中心化转发服务器**：本产品没有官方运营的私有中继、音视频流媒体或信令服务器，发布方不承担任何远程中转流量费用。公网接入依托 Cloudflare 官方提供的免费公共隧道服务。
- **不修改宿主机网络环境**：应用不会修改操作系统的防火墙、路由表或系统网络代理。
- **语音消耗用户自备额度（BYOK）**：手机远程语音所使用的语音识别（ASR）与语音合成（TTS）服务，均调用用户自己在桌面端配置的 DashScope API Key，由用户的阿里云百炼账号自行结算，与桌面端使用完全一致。

## 七、手机语音使用方法

1. **按住说话，松开发送**：
   - 在手机聊天界面底部按住语音按钮开始说话，松开后录音结束并提交识别。
   - 录音过程中界面会实时显示 ASR 转写流式临时文本，松开后定格为最终文本。
2. **转写结果直接进入角色对话**：
   - 最终文本自动作为用户的当轮输入发送给当前会话的角色，角色根据设定开始流式回复。
   - 手机语音输入仅用于与角色进行自然对话；若需要委派助手执行代码、文件操作或运行命令，请通过文字输入框提交。
3. **仅角色自然语言回复朗读**：
   - 角色的自然语言回复在 PC 端合成语音后下发至手机端自动播放（使用角色绑定的音色；未绑定时使用用户全局默认音色）。
   - 助手的代码分析、工具调用、运行日志、思考过程和系统提示**永远静音**，仅在手机端以结构化卡片呈现。
4. **按需合成，无手机在线不消耗额度**：
   - 当没有手机客户端在线且桌面端未开启语音朗读时，系统不会触发额外的 TTS 音频合成，不浪费用户的 API 额度。

## 八、常见问题与故障排查

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| 点击语音按钮提示麦克风权限被拒 | 手机浏览器未授予本站点录音权限 | 点击浏览器地址栏左侧的设置/锁形图标，将「麦克风」权限设为「允许」，然后刷新页面重试。 |
| 手机页面显示语音不可用或灰色禁用 | 地址栏不是 HTTPS 或使用了旧局域网 HTTP 地址 | 检查手机地址栏：必须以 `https://` 开头。若是之前使用局域网地址保存的书签，请在手机浏览器中清除该站点的缓存数据，重新扫描桌面端的公网 HTTPS 二维码。 |
| 扫描二维码打不开页面 | 隧道已重新启动，旧域名失效；或电脑休眠 | 确认电脑未休眠且桌面端处于运行状态；检查桌面端「设置 → 远程设备」中公网接入状态是否为「已就绪」；若曾重启过应用，请重新扫描最新的二维码。 |
| 配对提示“配对码错误”或“已被暂时封锁” | 输入了旧配对码或连续输错超限 | 桌面端每次生成新码都会让旧码立即失效，请以桌面端当前显示的 6 位数字为准；若因连续输错触发封锁，请等待界面提示的倒计时结束后再试。 |
| 提示“授权已过期，请重新配对” | 设备令牌达到 30 天或 7 天未使用失效 | 属于预期的令牌安全周期，在电脑端重新生成一枚配对码，在手机端重新配对一次即可继续使用。 |
| 页面能正常对话，但角色回复没有声音 | 未配置 DashScope Key 或角色音色合成失败 | 检查桌面端「设置 → 语音设置」中 DashScope API Key 是否有效且账户余额充足；查看界面上的失败提示日志排查具体报错。 |
