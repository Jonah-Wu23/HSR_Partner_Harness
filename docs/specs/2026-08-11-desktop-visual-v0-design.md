## 1. 视觉论点

这不是一个"带皮肤的聊天框"，而是一间两人常驻的工作室：角色与你交谈，机械助手在一旁真实作业。界面的一切层级都为三个问题服务——谁在说话、谁在干活、干到哪了。

设计由此得出三个不动摇的决定：

1. **身份优先于装饰**。角色（蓝系）与助手（青铜金系）的品牌色只出现在身份相关处：面板色点、气泡、搭档芯片、委派提示。其余界面保持中性安静，品牌色因此始终可读。
2. **状态用三通道表达**。运行、成功、失败、审批同时用"图标 + 文字 + 颜色"表达，颜色永远不是唯一提示。
3. **导航即状态板**。左侧导航不仅用于切换，还持续回答"哪个项目在跑任务、哪个路径失效、我当前在哪"。

通用装饰删除清单：无营销 hero、无渐变背景、无玻璃拟态、无卡片拼盘、无纯装饰图标、无逐字跳动动画。

## 2. 设计令牌草案

全部界面由语义 CSS Variables 驱动，`[data-theme="dark" | "light"]` 挂载在根节点，首次绘制前写入。组件不保存原始色值常量。Kimi 语义（fills / labels / separator / status）映射到本项目令牌；品牌色值锁定不动。

### 2.4 字阶与字体

- UI 字体：`'Microsoft YaHei UI', 'Segoe UI', 'PingFang SC', sans-serif`
- 等宽字体：`'Cascadia Mono', Consolas, monospace`（命令、路径、日志、代码）

| 角色 | 规格 | 用途 |
|---|---|---|
| `--font-t2` | 16/24 常规 | 输入框、消息正文 |
| `--font-b1` | 15/22 常规 | 面板标题辅助 |
| `--font-b2` | 14/20 常规/500 | 列表、按钮、标签（主 UI 字号） |
| `--font-c1` | 12/18 常规/500 | 时间、状态、元信息（最小字号） |
| `--font-title` | 15/24 700 | 应用名、面板标题 |

不使用 15px 以下的正文；不为装饰引入新字体。

### 2.5 圆角、间距、阴影、动效、层级

- 圆角：`4 / 8 / 10 / 12 / 16 / full`。气泡与面板 12，卡片 10，32px 控件 10，小控件 8，徽标 4，状态点与项目徽章圆形。
- 间距：`4 / 8 / 12 / 16 / 20 / 24 / 32`，层级越深间距越小。
- 阴影：仅菜单 / 弹层使用 `0 4px 16px rgba(0,0,0,.18)`（深色）/ `.10`（浅色）+ 0.5px `--separator` 描边；输入聚焦用 1px accent 描边而非阴影；Modal/Dialog 无描边靠遮罩。
- 动效：按压 100–160ms；Tooltip 125ms（首个延迟 300ms，后续瞬时）；菜单 / 弹层 150–250ms；抽屉 250–400ms；统一 `cubic-bezier(0.23,1,0.32,1)`  ease-out，退出时长为进入的 75%；只动 `transform` / `opacity`；`prefers-reduced-motion` 下保留透明度过渡、去掉位移。
- z-index：toast 1000 / tooltip 900 / dialog 850+860 / modal 800+810 / 无固定 header 层（顶栏在文档流内）。
- 等待反馈：运行中用状态点脉冲（1.6s 呼吸）与进度条；流式文字稳定上屏，不逐字弹跳。

## 3. 左侧导航规格（方案二·双层导航）

### 3.1 结构

```
┌────────┬───────────────────────┬─────────────────────────┐
│ 项目轨道 │ 聊天栏 224px           │ 工作区（角色区/双栏）      │
│ 56px   │                       │                         │
└────────┴───────────────────────┴─────────────────────────┘
```

**项目轨道（56px，--bg-rail，无文字）**，自上而下：

1. 日常聊天入口（对话图标，常驻顶部，选中态 = 图标底色块）。
2. 项目徽章列表：每个项目一枚 32px 圆形徽章（项目名首字），外圈状态环：
   - 蓝点呼吸 = 该项目有任务运行中；
   - 警告角标（⚠ 图标 + 文字 tooltip）= 路径失效；
   - 当前项目 = 徽章底 `--fill-selected` + 左侧 3px accent 缘条。
3. 底部：`＋` 新建项目按钮。

**聊天栏（224px，--bg-nav）**：

1. 栏头（48px）：当前项目名（截断）+ 路径健康徽标（✓ 正常 / ⚠ 失效）+ 项目设置入口（MoreIcon 菜单）；日常聊天语境下显示"日常聊天"且无协作入口。
2. `＋ 新建聊天` 主按钮（accent，32px，全宽）。
3. 搜索框（图标 + 占位"搜索聊天…"，过滤当前列表）。
4. 聊天列表，分组：`运行中` / `今天` / `更早`（按最后活跃归组，`运行中` 为状态分组置顶）。行结构：
   - 标题（14/20 500，截断）；
   - 副行：搭档芯片（角色×助手，12px，身份色点）+ 相对时间；
   - 运行中行：标题左侧 8px 蓝色呼吸点；
   - 当前聊天：`--fill-selected` 底 + 左侧 3px accent 缘条；
   - hover：`--fill-hover` + 行尾 MoreIcon（重命名 / 归档）。
5. 底栏：主题切换（DarkModeIcon / LightModeIcon 图标按钮，带 tooltip）+ 收起按钮（CollapseIcon）。

### 3.2 折叠态

- 收起 = 只留 56px 项目轨道；点击任意项目徽章或日常聊天入口即展开聊天栏。
- 折叠 / 展开 250ms ease-out 宽度过渡；工作区不重建，输入草稿保留。
- 折叠后轨道仍完整呈现：当前项目缘条、运行呼吸点、路径失效角标、新建项目入口。

### 3.3 异常与空状态（就地处理）

| 状态 | 表现 |
|---|---|
| 无项目 | 聊天栏显示空态：图标 + "还没有项目" + `＋ 新建项目` 主按钮 |
| 项目无聊天 | 列表区显示"这个项目还没有聊天" + 新建聊天按钮 |
| 路径失效 | 轨道徽章带 ⚠ 角标；栏头路径徽标变警告色；聊天栏顶部插入就地说明条："文件夹不可访问：<路径>" + "重新选择文件夹" 按钮；聊天可浏览历史但禁用新建与执行任务（视觉置灰 + tooltip 说明） |
| 搜索无结果 | 列表区显示"没有匹配的聊天" |
| 列表超长 | 项目徽章与聊天列表超过阈值后虚拟化滚动 |

## 4. 其余区域规格概要

### 4.1 顶栏

高 48px，文档流内不定住。左侧：应用名（Pair Harness）+ 当前搭档副题（白厄 × 神秘的古代机械，身份双色点）；中间：聊天 / 协作模式 Segmented Control（md，2 段）；右侧：取消当前任务（danger outline，仅运行中可用）。日常聊天语境下模式切换隐藏协作段并禁用。

### 4.2 聊天模式

角色区占满内容区，消息列居中限宽 760px。用户气泡右置中性色；角色气泡左置蓝系；系统短句居中弱灰；模型思考默认折叠（12px 行 + 右箭头）。

### 4.3 协作模式与助手工作台

角色区 : 工作台 ≈ 55 : 45，6px 拖动分栏条（hover 显 accent 色）。工作台自上而下：助手自然语言消息流（青铜金气泡）→ 工具卡片流。助手执行期间角色区照常可聊。

工具卡片（摘要优先 + 可展开）：

- 头行：状态图标（运行=旋转/呼吸、成功=✓、失败=✕、取消=−）+ 动作类型（`codex exec` 等等宽字体）+ 右侧状态文字与耗时 + 展开箭头。
- 摘要行：一句话结果（14/20）。
- 展开区：工作目录、变更文件、命令与输出（等宽、`--reasoning` 底色块、横向滚动、无逐行入场动画）。
- 左侧 3px 状态色条沿用 PyQt 语义；卡片底 `--bg-card` + `--separator` 细边。
- 同一 `tool_call_id` 原位更新，不重排。

### 4.4 输入区

主容器：`--bg-input` + `--separator` 描边 + radius 16，聚焦时 accent 描边。结构：

- 上行：发送目标切换（对角色说 / 交给助手，分段控件或目标徽章；日常语境与聊天模式只有"对角色说"）+ 多行输入（Enter 发送、Shift+Enter 换行）+ 发送主按钮。
- 下行工具条：左侧审批模式下拉（请求批准 / 帮我审核 / 完全允许运行）与推理档位；右侧 VAD 开关、PTT（按住说话，按下 / 录音中 / 松开三态）、TTS 停止。
- ASR 临时转写以弱化样式覆盖在输入区，不改变工具条位置。

### 4.5 审批条

固定在输入区正上方，全宽，`--bg-card` + warning 色描边 + radius 12，出现 / 收起 200ms 高度 + 透明度过渡，不遮挡已发消息。

- 请求批准：操作摘要（等宽命令 + 影响文件数）+ 三按钮：允许（primary）/ 本对话内允许（secondary）/ 否决（danger outline）；点击后立即禁用，收到 resolved 后收起；多请求排队逐条展示。
- 帮我审核：无按钮，显示"审查中…"与最终裁决文字（允许=success / 否决=danger，附理由与调整建议）。
- 完全允许运行：不出现。

### 4.6 语音状态

输入区右下工具条承载全部语音状态：VAD 状态点（待机 muted / 聆听 success / 说话 accent / 识别 secondary / 误触发 warning / 播放 accent）+ 状态文字（12px）；TTS 播放时"停止语音"按钮可用。语音状态变化只改色点与文字，不做持续位移动画。

### 4.7 弹层与反馈

- 菜单：bg-elevated + 0.5px 描边 + 小阴影，item 36px，radius 12/10，min 140 / max 240px。
- Tooltip：深底 `#2B2B2B` 白字，125ms，首个延迟 300ms。
- Toast：顶中，深底胶囊，success/error/info/loading/caution 五型，3s 自动消失。
- Dialog：360px 固定宽，alertdialog，无关闭按钮；用于归档确认等二元选择。
- Modal：medium 560px，用于需要表单的场合（如重命名若不做行内编辑）。

## 6. v0 检查清单（实现时逐项验收）

- 窗口：1180×760、1440×900、1920×1080；Windows 缩放 100% / 125% / 150%。
- 主题：浅色 / 深色全界面截图；切换不重建业务状态、无错误主题闪帧。
- 数据状态：空项目、单项目单聊天、多项目多聊天长标题、路径失效、运行中任务、500 条消息、流式更新、工具卡片持续更新、长文件路径。
- 交互：键盘 Tab 顺序、焦点可见、Esc 关弹层、菜单箭头键、reduced motion。
- 性能：500 条消息虚拟列表滚动稳定；流式 delta 合并周期内上屏；动画只动 transform/opacity。

## 7. 视觉自评

- 来自角色关系的选择：身份双色系统只在身份处使用；搭档芯片把"角色×助手"关系带进每一行聊天；工具卡片保持"机器作业记录"的冷静质感（等宽、状态色条、无装饰）。
- 来自编程 Harness 场景的选择：项目轨道全局状态板、审批条位置稳定、工具卡片摘要优先、命令日志静音且结构化。
- 已删除的通用装饰：渐变、玻璃拟态、卡片拼盘、营销式空态插画、逐字动画、多重描边。
- 与 Kimi 的关系：借用 Quiet Utility 的语义分层、组件状态完备性与动效纪律；不复制其配色与布局，品牌色与双层导航结构为本项目独有。
