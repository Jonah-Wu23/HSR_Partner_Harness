# HSR Partner Harness v0.3.2-patch1

v0.3.2-patch1 是 v0.3.2 的构建修复版，功能与 v0.3.2 一致。

## 本版本修复

- 修复 CI 失败：`desktop/src-tauri/src/main.rs` 三处代码未按 rustfmt 格式提交，`cargo fmt --check` 失败导致 Rust checks job 挂掉。
- 修复 CI 失败：`tests/unit/test_concurrent_entries.py` 中"跨聊天并发"测试使用共享 `asyncio.Event` 做第二次等待，事件置位后 `wait()` 立即返回，断言与 chat-b 任务启动竞态；改为按会话区分的 `started_for(conversation_id)` 事件，真正等待 B 聊天推进到自己的工具事件。
- 修复 CI 失败：`tests/unit/test_voice_runtime.py` 的 PTT 测试在 finally 中依赖 `states[-1] == "listening"` 且只等 3s，慢 CI 上播放恢复链延迟即超时；改为等待确定性信号 `vad.sessions` 递增（播放循环重开 VAD 会话的确切证据），超时放宽到 15s。
- 版本号同步为 `0.3.2-patch1`（Python、前端、Tauri、Rust 四处）。
