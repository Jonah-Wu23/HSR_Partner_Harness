# HSR Partner Harness v0.2.5 发布说明

## 本次发布

v0.2.5 是面向 Windows x64 的正式版本，包含本轮角色对话、任务委派、语音和供应商切换修复。

## 主要更新

- 统一模型供应商行为：引导页或设置选择 OpenAI OAuth/API 时，白厄和神秘的古代机械都使用 GPT；选择 DeepSeek 时，两者都使用 DeepSeek。
- 修复 DeepSeek 与 OpenAI OAuth 之间切换后无法登录或运行时仍使用旧配置的问题。
- 修复典型角色委派链路，保留真实的任务运行、工具记录和最终结果；失败会显示真实失败，不用伪造成功结果遮蔽根因。
- 修复委派过程失败但最终结果成功时的状态判断，使最终结果决定任务状态。
- PTT 改为点击开始、再次点击结束，右 Alt 使用同一切换行为；默认 PTT 键位为右 Alt。
- VAD 默认关闭；角色和古代机械的语音开关分别在语音设置中管理，古代机械语音默认关闭。
- 安装包内置 Python Sidecar、Codex、DeepSeek-Reasonix 与 VAD 资源。

## 构建与验证

- Python、前端、TypeScript、Rust 测试和生产构建均在发布前执行。
- 发布资产包含 Windows x64 NSIS 安装包和可直接运行的 EXE。
- 安装包发布前已清理本机首次登录数据，首次启动进入新用户状态。

## 已知事项

- OpenAI OAuth 首次使用仍需要在系统浏览器中完成登录。
- 真实模型调用需要用户在引导页或设置中配置对应供应商；发布包不包含个人账号、API Key 或本地会话数据。
