删除「角色」？

角色的全部字段、世界书条目与头像将被移除，且无法恢复。已绑定的音色会一并解除绑定。原型阶段此操作仅演示确认流程，不改动数据。

归档「角色」？

归档后角色将从列表默认隐藏，不删除任何数据。需要时可在来源筛选中选择「已归档」查看，并随时恢复。原型阶段此操作仅演示确认流程，不改动数据。
