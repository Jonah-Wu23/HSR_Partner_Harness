# 手机远程语音说明

本指南面向想在手机浏览器上用「按住说话」和角色对话的用户，说明为什么需要 HTTPS、推荐的自组网做法、使用方式与常见问题排查。适用版本：V0.3.5 及以后。

## 一、为什么手机上需要 HTTPS 才能用语音

浏览器（Chrome、Safari 等）把麦克风采集列为**安全上下文专属能力**：只有通过 HTTPS 加密连接打开的页面，才被允许调用麦克风。这是所有浏览器统一执行的安全边界，**不是本应用的缺陷**。

电脑桌面端的远程服务默认以 `http://<电脑局域网地址>:8765` 的方式伺服。在这种纯局域网 http 地址下：

- 配对、聊天列表、文字消息、审批等全部功能照常可用；
- 手机上的**语音入口会被如实禁用**，并提示原因（缺少 HTTPS）。

应用不会伪装可用，也不会引导你绕过浏览器的安全检查。想让手机语音可用，需要一个 HTTPS 入口，下文给出推荐的搭建方式。

## 二、推荐做法：用 Tailscale 打开 HTTPS 通道

[Tailscale](https://tailscale.com) 是一款免费的组网工具：它把你自己的设备（电脑、手机）组成一个仅限本人账号访问的虚拟网络，并自动为你的设备提供受信任的 HTTPS 证书。流量走 Tailscale 的加密通道，本应用全程不需要任何第三方服务器参与。

### 准备

- 一台运行本应用的 Windows 电脑；
- 一部能安装应用的手机（iOS 或 Android）；
- 一个可用于登录 Tailscale 的账号（支持 Google、Microsoft、GitHub、Apple 等常见登录方式）。

### 步骤

1. **电脑安装 Tailscale 并登录。** 从 Tailscale 官网下载 Windows 版，安装后登录你的账号。
2. **手机安装 Tailscale 并登录同一账号。** 在应用商店搜索 Tailscale 安装，登录与电脑相同的账号。此时两台设备已处于同一个虚拟网络。
3. **在电脑上开启 HTTPS 反向代理。** 打开 PowerShell 或命令提示符，执行：

   ```
   tailscale serve --bg 8765
   ```

   这条命令把电脑上 8765 端口的远程服务以 HTTPS 方式暴露给你的虚拟网络。`--bg` 表示后台常驻，重启电脑后需重新执行一次。
4. **找到电脑的专属网址。** 形如 `https://<设备名>.<域名>.ts.net`。查看方式任选其一：
   - 执行 `tailscale serve status`，输出中会显示代理状态；
   - 登录 Tailscale 管理后台的设备列表页，每台设备都标有完整的 ts.net 域名，可直接复制。
5. **手机访问该网址。** 保持手机的 Tailscale 处于开启状态，用浏览器打开第 4 步的 `https://…ts.net` 地址，会看到熟悉的配对页。
6. **配对。** 在电脑端打开「设置 → 远程设备」，把上面显示的 6 位配对码输入手机配对页（也可填写设备名称后开始配对）。配对成功后进入聊天，语音入口即可使用。

> 说明：桌面端二维码里编码的是局域网 http 地址，在 Tailscale 场景下请按上面的方式手动输入网址访问；配对码本身不受影响，仍然从「设置 → 远程设备」读取。

### 连接与证书说明

- 通过该地址访问时，页面是 HTTPS 加载的，手机与电脑之间的实时数据连接自动升级为 `wss` 加密 WebSocket——TLS 由 Tailscale 提供并终结，电脑端服务本身无需任何改动。
- `ts.net` 域名的证书由 Tailscale 自动申请签发（公共可信证书），正常情况下浏览器不会出现警告。
- 若你的 Tailscale 账号是较早注册的，首次使用可能需要在管理后台的 DNS 设置页确认 MagicDNS 与 HTTPS 已启用（新账号默认开启）。
- 使用期间两端都要保持 Tailscale 在线；电脑关机、应用退出或任一端退出 Tailscale，手机将无法访问。

## 三、明确的边界

以下为本产品的固定设计，写在此处以免误解：

- **不内置自签证书方案。** 应用不会生成自签名证书，也不会建议你忽略浏览器证书警告。
- **不提供任何服务器。** 本产品没有发布方运营的中继、信令、推送或语音转发服务器。远程能力只存在于「局域网直连」和「你自建的虚拟网络」两种形态，Tailscale 属于后者。
- **语音消耗你自己的额度。** 手机语音使用的语音识别与合成服务，用的是你在设置中配置的 DashScope API Key 和你的账户额度，与其他功能一致。

## 四、手机语音怎么用

- **按住说话，松开结束。** 在聊天界面按住语音控件开始录音，松开后录音结束；识别到你停止说话时也可能自动结束本次录音。录音过程中转写文本会在手机上实时显示（先出现临时结果，再定格为最终文本）。
- **转写文本直接进入对话。** 松开后，最终转写文本作为你这一轮的发言发送给当前聊天的角色，角色据此回复。手机语音只用于和角色聊天——委派任务仍需通过文字输入发起。
- **只有角色回复会朗读。** 角色的自然语言回复会在电脑端合成语音、下发到手机播放（使用该角色绑定的音色，未绑定则使用你的账号音色）。助手消息、工具记录、思考过程、系统提示**永远静音**，只以文字和结构化卡片展示。
- 没有手机在线时，电脑端不会为手机预合成音频，也不产生额外消耗。

## 五、常见问题排查

| 现象 | 处理 |
| --- | --- |
| 点语音按钮提示麦克风权限被拒 | 在浏览器对该站点的设置里把「麦克风」改为允许（通常通过地址栏左侧的锁形/滑块图标进入），然后刷新页面重试。 |
| 浏览器出现证书警告 | `ts.net` 域名使用的是公共可信证书，正常不应报警告。请核对地址拼写是否与 Tailscale 显示的完整域名一致，确认手机 Tailscale 已登录且在线后重新访问。 |
| 语音入口仍是禁用状态 | 检查手机地址栏：必须是 `https://` 开头而不是 `http://`。若之前用局域网 IP 地址配对过，浏览器可能记住了旧地址——清除该站点的站点数据（Cookie 与网站数据）后，改用 `https://…ts.net` 地址重新访问配对。 |
| 页面完全打不开 | 依次确认：电脑已开机且本应用正在运行；两端 Tailscale 都在线；电脑上的反代仍在生效（可在电脑重新执行 `tailscale serve --bg 8765`，并用 `tailscale serve status` 核对）。 |
| 能连上但没有声音 | 确认已在设置中配置 DashScope API Key 且账户有余额；角色的音色创建成功与否也会影响朗读。失败信息会如实显示在界面上，按提示处理即可。 |
