# v0.2.0 发布说明

> 本文档由强逻辑 AI 在 V0.2.0 执行期维护，M5 定稿；最终检查与交付 AI 在
> 发布前核对内容与实际变更一致后发布。

## 版本目标

按《V0.2.0版本修改方案.md》补齐消息生命周期、流式输出、任务队列、错误恢复、
本地账号与配置中心等基础 Harness 能力；接入视觉方案（见视觉线最终交付文档）。
覆盖 M0 记录的 14 个问题。

## 新增能力

- **消息真实回执**（问题 1）：提交同步落库、返回真实 `message_id`，后台回合
  按 `message.status` 生命周期推进，失败保留文字可重试。
- **独立聊天模式**（问题 3）：模式由后端按会话持久化（`conversation.set_mode`），
  不被推理档位/审批方式/发送对象覆盖；聊天模式是角色能力边界（不能委派）。
- **消息路由**（问题 7）：`target`/`origin`/`delegation_id` 字段，Presenter 按
  目标切分角色区与工作台，`user+target=assistant` 只进工作台。
- **项目运行上下文**（问题 5）：项目名/目录/时间/时区/模式注入角色系统提示词。
- **审查生命周期**（问题 14）：`review.started/completed/failed` 只在真正调用
  审查智能体时触发；异常按安全默认否决。
- **TTS 空文本防护**（问题 2）：纯标点/空白文本不进入 TTS 与朗读队列。
- **流式输出**（问题 10）：DeepSeek JSON 流增量解析，只上屏干净台词；
  推理独立通道（`reasoning.*`），原始 JSON 进入技术详情绝不进气泡。
- **统一运行模型**（问题 6/13）：一次提交 = 一个 Turn（`turn.*` 生命周期事件），
  快照可水合。
- **持久化会话队列**（问题 9）：忙碌时提交入队（`conversation_inbox` 落库），
  支持编辑/撤回/调序，回合完成自动派发。
- **连续音频输出**（问题 11）：长生命周期输出流、有界缓冲、跨块连续播放，
  停播/跳过即时生效。
- **错误分级与连接恢复**（问题 12）：`error.reported` 分级
  （fatal/recoverable/info），Sidecar 异常退出自动重连（退避），
  手动重连命令。
- **本地账号与配置中心**（问题 13）：多账号注册/登录/切换，账号级配置与
  密钥隔离（密钥只回显掩码），Codex 两类登录状态（浏览器 OAuth / API Key，
  每账号独立数据目录），DeepSeek 编程助手（Reasonix ACP）引擎选择，
  语音试听与连接测试。
- **GPT-5.6 Sol 编程助手**：编程任务固定发送给 `gpt-5.6-sol`，Composer
  的轻度/中/高/极高/最高分别映射为 `low`/`medium`/`high`/`xhigh`/`max`。
- **视觉方案接入**（M4）：账号门与首次引导、设置中心四页、Toast 分级、
  排队条（编辑拉回输入区/撤回/立即插入）、委派卡、思考缎带流式、
  语音迷你播放条。

## 变更要点

- 数据库结构版本 6（新增 accounts / account_preferences / provider_configs /
  secret_refs / conversation_inbox；projects 增加 account_id）；旧库自动迁移，
  现有项目归入默认账号。
- Sidecar 协议新增命令：`conversation.set_mode`、`queue.edit/withdraw/
  prioritize`、`app.reconnect`、`account.*`、`config.*`、`codex.*`、
  `voice.tts_play/tts_skip/preview`。
- 新增事件：`turn.started/status_changed`、`queue.changed`、
  `connection.status/restored`、`review.*`、`message.status_changed`。
- 第三方：DeepSeek-Reasonix（ACP 客户端）使用情况记入 THIRD_PARTY_NOTICES.md。

## 升级说明

首次进入新版时创建默认本地账号并设置名称/密码；现有项目自动归入该账号。
