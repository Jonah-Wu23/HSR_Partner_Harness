## 3. 真实联调（脚本 `scripts/smoke_serve_mode.py`，真实子进程）

真实 `python -m pair_harness.desktop_backend --demo --serve <port>` 进程，11 项全过：

1. 进程启动，backend.ready 到 stdout；
2. stdin `remote.issue_code` 生成 6 位配对码；
3. stdin `card.list` 返回 3 个内置角色（stdin 循环与 WS 并行不受影响）；
4. WS 未鉴权 `app.bootstrap` 被拒（missing_token）；
5. WS `remote.pair` 配对换 token；
6. WS 带 token `app.bootstrap` 成功，response 回同一连接；
7. stdin 触发 `conversation.rename`，WS 收到扇出事件 `conversation.changed`（sequence 单调）；
8. stdin `remote.revoke` 撤销；
9. 已撤销 token 再连被真实拒绝；
10. `app.shutdown` 后进程退出码 0；
11. 端口释放无残留。
