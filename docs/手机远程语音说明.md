# 手机远程语音说明

本指南面向想在手机浏览器上用「按住说话」和角色对话的用户，说明为什么需要 HTTPS、怎么打开一条 HTTPS 通道、接入时要注意什么、使用方式与常见问题排查。

适用版本：V0.4.0 及以后。V0.3.5—V0.3.9 的 HTTPS 接入方式不同（需要用户自行搭建 Tailscale 通道），升级后请按本文操作。

## 一、为什么手机上需要 HTTPS 才能用语音

浏览器（Chrome、Safari 等）把麦克风采集列为**安全上下文专属能力**：只有通过 HTTPS 加密连接打开的页面，才被允许调用麦克风。这是所有浏览器统一执行的安全边界，**不是本应用的缺陷**。

桌面端默认只在电脑本机（回环地址）上提供远程服务，手机无法直接访问。即使用户另外开启了局域网直连，那条通道是纯 http 的，在这种地址下：

- 配对、聊天列表、文字消息、审批等全部功能照常可用；
- 手机上的**语音入口会被如实禁用**，并提示原因（缺少 HTTPS）。

应用不会伪装可用，也不会引导你绕过浏览器的安全检查。想让手机语音可用，需要一个 HTTPS 入口，下文给出推荐的搭建方式。

## 二、推荐做法：用 Cloudflare Tunnel 打开 HTTPS 通道

[Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 是 Cloudflare 提供的隧道服务。运行在电脑上的 `cloudflared` 组件**主动向外拨出一条加密长连接**，Cloudflare 边缘把公网请求顺着这条连接送回你的电脑。整个过程不需要公网 IP、不需要在路由器上开端口、不需要注册 Cloudflare 账号，手机侧也不需要安装任何客户端。

### 方式一：在应用内开启（推荐）

1. **确认应用已登录并进入主界面。** 隧道需要一个运行中的桌面端才能建立。
2. **打开「设置 → 远程设备」，开启「公网接入」开关。** 首次开启时应用会下载 `cloudflared` 组件（约 45 MB），下载与校验进度会显示在界面上。
3. **等待状态变为「已就绪」。** 就绪后该页显示本次分配的 `https://<随机主机名>.trycloudflare.com` 地址，并自动生成含该地址的配对二维码。
4. **手机打开该地址或扫描二维码。** 手机可以用蜂窝网络，不必和电脑连同一个 Wi-Fi。
5. **配对。** 在电脑端「设置 → 远程设备」查看 6 位配对码，输入手机配对页（也可填写设备名称后开始配对）。配对成功后进入聊天，语音入口即可使用。

> 关闭开关即断开隧道。隧道关闭后，任何仍在用该地址的手机都会立即失去连接。

### 方式二：自己运行 cloudflared（进阶）

已经自备隧道、自有域名或自建反向代理的用户，可以继续用自己的一套。需要满足的条件是：把请求转发到电脑回环地址上的远程服务端口，并在传输层提供受信任的 HTTPS 证书。其余接入步骤与方式一相同。

### 连接与证书说明

- 地址是 `https://` 加载的，手机与电脑之间的实时数据连接自动升级为 `wss` 加密 WebSocket。TLS 由 Cloudflare 边缘终结，电脑端服务本身无需任何改动。
- 证书由 Cloudflare 提供，属于公共可信证书，正常情况下浏览器不会出现警告。
- **主机名每次开启隧道都会重新分配**，上一次的地址随即失效。电脑重启、应用重启或开关一次隧道之后，都需要重新扫码配对。
- 使用期间电脑要开机且应用在运行。电脑休眠、关机或退出应用，手机会断开——这是预期行为，界面会如实提示，不会假装仍在后台运行。

## 三、接入安全须知

公网隧道把服务放到了互联网上，以下几点需要知道。

**地址不是秘密。** `trycloudflare.com` 下的主机名会进入公开的证书透明度日志，任何人都能枚举到新出现的主机名。地址被陌生人扫到是常态，不要靠「地址只有我知道」来获得安全感，也不要在公开场合张贴配对二维码截图。

**真正的防线是配对码与设备令牌。** 未配对的连接只能做一件事：提交配对码。配对码是 6 位数字、短期有效、只能使用一次。连续输错会被暂时封锁，所以暴力猜测走不通。

**设备令牌有寿命。** 配对成功后签发的令牌有有效期（最长 30 天，连续 7 天不使用也会失效）。到期后手机会提示需要重新配对，这是正常流程。

**控制操作只在本机生效。** 生成配对码、查看与撤销设备、开关隧道这些操作只在电脑本机的界面上可用。手机端即使已经配对，也不能给自己或别的设备补发配对码，不能撤销其他设备。

**撤销立即生效。** 在「设置 → 远程设备」撤销某台设备后，该设备的连接当场断开，旧令牌无法再用。

**局域网直连默认关闭。** 远程服务默认只监听电脑本机。确需在同一 Wi-Fi 内直连时，可在设置中显式开启局域网监听，此时界面会持续显示暴露提示。在用公网隧道的情况下，建议保持关闭。

## 四、明确的边界

以下为本产品的固定设计，写在此处以免误解：

- **不内置自签证书方案。** 应用不会生成自签名证书，也不会建议你忽略浏览器证书警告。
- **不运营发布方服务器。** 本产品没有发布方运营的中继、信令、推送或语音转发服务器，也不承担任何流量费用。公网接入使用 Cloudflare 的匿名隧道，流量经由 Cloudflare 边缘转发，由你在本机主动开启与关闭。
- **不接管你的网络环境。** 应用不会修改路由器、防火墙或系统代理设置。
- **语音消耗你自己的额度。** 手机语音使用的语音识别与合成服务，用的是你在设置中配置的 DashScope API Key 和你的账户额度，与其他功能一致。

## 五、手机语音怎么用

- **按住说话，松开结束。** 在聊天界面按住语音控件开始录音，松开后录音结束；识别到你停止说话时也可能自动结束本次录音。录音过程中转写文本会在手机上实时显示（先出现临时结果，再定格为最终文本）。
- **转写文本直接进入对话。** 松开后，最终转写文本作为你这一轮的发言发送给当前聊天的角色，角色据此回复。手机语音只用于和角色聊天——委派任务仍需通过文字输入发起。
- **只有角色回复会朗读。** 角色的自然语言回复会在电脑端合成语音、下发到手机播放（使用该角色绑定的音色，未绑定则使用你的账号音色）。助手消息、工具记录、思考过程、系统提示**永远静音**，只以文字和结构化卡片展示。
- 没有手机在线时，电脑端不会为手机预合成音频，也不产生额外消耗。

## 六、常见问题排查

| 现象 | 处理 |
| --- | --- |
| 点语音按钮提示麦克风权限被拒 | 在浏览器对该站点的设置里把「麦克风」改为允许（通常通过地址栏左侧的锁形/滑块图标进入），然后刷新页面重试。 |
| 浏览器出现证书警告 | Cloudflare 提供的是公共可信证书，正常不应报警告。请核对地址拼写是否与桌面端显示的完整地址一致后重新访问。 |
| 语音入口仍是禁用状态 | 检查手机地址栏：必须是 `https://` 开头而不是 `http://`。若之前用局域网地址配对过，浏览器可能记住了旧地址——清除该站点的站点数据（Cookie 与网站数据）后，改用 `https://…trycloudflare.com` 地址重新访问配对。 |
| 二维码扫不出来了 | 隧道的主机名每次开启都会变，上一次的二维码已失效。回到「设置 → 远程设备」确认状态为「已就绪」后重新生成。 |
| 页面完全打不开 | 依次确认：电脑已开机且本应用正在运行；「设置 → 远程设备」里公网接入处于开启且状态为「已就绪」；电脑没有休眠。状态不对时按界面提示处理，不要反复扫码。 |
| 提示授权已过期，要求重新配对 | 设备令牌已到期（最长 30 天，或连续 7 天未使用）。在电脑端重新生成配对码后配对一次即可，这是正常的定期更换。 |
| 配对时提示失败或被暂时封锁 | 核对配对码是否为桌面端当前显示的那一枚（重新生成配对码会让旧码立即作废）。连续输错会触发暂时封锁，等待界面提示的时长后重试。 |
| 能连上但没有声音 | 确认已在设置中配置 DashScope API Key 且账户有余额；角色的音色创建成功与否也会影响朗读。失败信息会如实显示在界面上，按提示处理即可。 |
