# V0.3.4 验收记录

> 日期：2026-08-24
> 基线：V0.3.4 原 PR #4（合并提交 `650ffa9`）
> 验收分支：`v0.3.4-acceptance-fixes`

## 验收范围

本轮以 `docs/v0.3.3-wrap-up.md` 的 8 项缺陷为输入，复核 V0.3.4 对撤销断连、手机委派与普通对话、模式切换、角色思考隔离、语音边界、局域网配对地址、有序停机和打包资源的修改。同时检查进入 V0.3.5 前需要稳定的消息流、账号隔离与构建门禁。

## 结论

V0.3.3 记录的 8 项缺陷均有对应实现和回归测试。复审发现的阻塞项已在验收分支修复：

- 手机聊天事件统一由 `mobileStore` 按 `stream_id + sequence` 归并，删除 Hook 内第二套 WS 订阅，避免重复增量、旧会话流式消息泄漏和正文复制进角色思考。
- 手机与桌面的 `conversation.open` 增加请求代次，迟到响应不能抢回旧会话。
- 账号切换原子清空消息、审批、配对、语音、草稿及远程设备等账号级状态。
- 音色生成失败恢复为真实失败状态，同一说话方不能重复提交，旧页面请求结果不能写回新账号页面。
- WS 启动部分失败时回滚 `AppRunner`；已鉴权连接固定 token，避免撤销绑定与实际请求身份分叉。二次硬中断继续保留非零失败语义。
- 配对 URL 支持 IPv6；LAN 探测失败时不伪造回环地址。
- V0.3.4 版本号在 Python、npm、Tauri 与 Rust 元数据中同步。
- CI 增加手机端依赖安装、测试、类型检查和生产构建；打包脚本使用 `npm ci` 锁定依赖。

## V0.3.5 最小准备

本轮没有提前实现 V0.3.5 功能，只稳定其依赖的边界：手机端单一事件归并入口、跨账号状态隔离、会话装载代次和可复现的 mobile PWA 构建。
