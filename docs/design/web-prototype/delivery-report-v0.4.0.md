## 2. 视觉系统（硬性约束）

- **配色**：暗色优先，近黑底 + 单一琥珀橙 accent `oklch(0.72 0.15 65)`；浅色主题 `data-theme="light"`，accent 加深至 `oklch(0.62 0.16 60)` 保证白底对比度；localStorage 记忆。**全项目零蓝紫色值**（已 grep 核查）。
- **警示规则**：琥珀橙与警告色色相接近，所有警告/危险状态一律图标 + 文字双编码，不单靠颜色。
- **字体**：思源宋体 Display（角色名/标题）、Inter 正文、JetBrains Mono 字段与元数据。
- **图标**：全部线性 SVG，**零 emoji**（已 grep 核查，仅 ←/→ 排版箭头）。
- **布局**：8px 圆角、1px 边框、8px 基线网格；Bento 卡片网格 + Linear 克制层级 + Agentic 对话优先。
- **诚实标识**：所有演示数据带「样例数据」虚线标签；错误态透传真实错误摘要，不用默认角色掩盖失败。
